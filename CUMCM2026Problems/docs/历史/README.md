## 3. 与活跃文档的关系

- 活跃文档**只引用** `源材料/`（题面原文与队友原件）与 `文献/`（检索审计），不引用 `历史/`；
  唯一的例外是 [03](../03_证据与验证总表.md) 的 Q3-4 条目，它指向 `已合并/原03_…md` §5 的逐区间权重表。
- 若某条结论需要回溯到更详细的早期论证，从上表的"内容去向"列找到对应的活跃文档章节；
  仍不足时再回查归档原件。
