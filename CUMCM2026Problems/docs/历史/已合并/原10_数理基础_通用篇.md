## G1　守恒型有限体积离散及其必然产物

| 字段 | 内容 |
|---|---|
| **主张** | 用节点中心型有限体积（控制体法）离散圆柱径向方程；离散本身守恒，圆心与表面是**半控制体**，圆心不需要洛必达处理 |
| **类型** | 数学 + 数值 |
| **推导要点** | 环 `i` 的收支：`V_i·ρcp·dT_i/dt = G_{i−1/2}(T_{i−1}−T_i) + G_{i+1/2}(T_{i+1}−T_i) + 边界项`，`G_{i+1/2}=k_face·A_{i+1/2}/dr`。几何因子省去 `2πL`：中心 `V_0=(dr/2)²/2`、内部 `V_i=r_i·dr`、表面 `V_N=(R²−(R−dr/2)²)/2`（**半格**） |
| **计算证据** | ① 几何：`ΣV` 对比 `πR²` 到机器精度；② 内部通量成对抵消到舍入误差（二维守恒闭合 2.1×10⁻¹⁵）；③ 测试：`tests/test_grid.py`、`test_consistency.py`。路径：`AProblemMaterial/aproblem/grid.py`、`model.py` |
| **文献支撑** | L-05（有限体积法的守恒通量表述）、L-06（界面系数在异质/间断介质中的经典处理） |
| **强度** | Ⅰ（几何与配对守恒是代数恒等式）+ Ⅱ（数值复核） |
| **论文落点** | 6.1 数值方法 |
| **边界与反例** | 中心与表面若按整格 `r_i·dr` 计体积，热容与水分容量会错近一倍；"节点中心型"与"格心型"不可混称 |
| **缺口** | — |

## G2　界面扩散系数由通量守恒唯一确定（核心）

| 字段 | 内容 |
|---|---|
| **主张** | 界面上 `D` 取什么值**不是"选平均方式"**，而是被通量守恒唯一确定：`D_face = ΔΦ/ΔC`，`Φ(C)=∫₀^C D dc` 为基尔霍夫通量势；该式不含任何自由参数 |
| **类型** | 数学（恒等式） |
| **推导要点** | 界面上无物质累积 ⇒ 通量处处相等。对 `J = −D(C)·∂C/∂r` 沿界面区间积分得 `J·Δr = −∫D dc`，即 `D_face=ΔΦ/ΔC`。三套附录的 `D=A(T)e^{−b/C}` 有初等原函数 `Φ=A(T)[C·e^{−b/C} − b·E₁(b/C)]`（代换 `u=b/C`，`∫e^{−u}u^{−2}du=−e^{−u}/u+E₁(u)`），`dΦ/dC=D` 可直接验证 |
| **计算证据** | ① 解析 `Φ` 对 `scipy.integrate.quad` 数值积分：最大相对偏差 2.3×10⁻⁶；② 中心差分还原 `D`：1×10⁻⁴；③ 界面值对独立积分：1×10⁻⁵；④ 常数 `D` 时精确退化；⑤ 两侧 `C` 相等时不出现 0/0（`|ΔC|<10⁻⁶C` 退回点值）。路径：`aproblem/physics.py`、`interfaces.py`、`tests/test_kirchhoff.py` |
| **文献支撑** | L-01、L-02（基质通量势的提出与工程应用）、L-03（基尔霍夫变换同时适用于**分层与连续渐变**介质——正是本题情形）、L-04（基于基尔霍夫变换的非线性反应扩散数值解）；L-06 说明调和平均的成立前提是**真实分层**；L-07 是反面证据，说明不存在"某种平均普遍更优" |
| **强度** | Ⅰ |
| **论文落点** | 6.2 界面扩散系数（本文最核心一节） |
| **边界与反例** | ① 通量势只对 `C` 定义，而本题 `D` 还依赖 `T`，故在**同一个面温度** `T_f=(T_i+T_{i+1})/2` 上求 `Φ`；② 圆柱几何的对数因子 `g_i=Δr/(r_f·ln(r_{i+1}/r_i))` 未施加，`g_i−1` 最大 −3.82%（最贴轴的第一面）且随加密消失——属已量化的小量；③ 传热方程无通量势（热流是 `k∇T` 而非 `k∇C`），传热侧仍用中点值 |
| **缺口** | — |

## G4　端面降维与几何口径

| 字段 | 内容 |
|---|---|
| **主张** | ① `2h/L` 体积源项本身推导无误，但它依赖"端面状态≈同半径处轴向平均状态"的闭合假设；② 在 `L/R=12.5` 的本几何下该假设不成立（中截面按对称性轴向通量恒为零，却也被摊到了端面失水的"好处"）；③ 因此主结果应解释为**中截面的径向分布**，而端面对中截面的影响在 10⁻⁷ 量级 |
| **类型** | 数学（对称性）+ 数值（二维参考）+ 量级（解析上界） |
| **推导要点** | 二维轴对称方程沿 `z∈[0,L]` 积分得 `S_T=(2h/L)(T_air−T̄)`、`S_C=(2h_m/L)(C_air−C̄)`，闭合时令端面状态等于轴向平均。中截面：`∂T/∂z=∂C/∂z=0`。特征时间比 `((L/2)/R)²=39`，端面到中截面 12.5 cm 而径向只 2 cm |
| **计算证据** | ① **二维轴对称材料坐标模型**（端面为真实 Robin 边界）：40×20 / 40×40 / 40×80 的达标时刻 51.1837 h，三档差 1.6×10⁻⁸；② 二维中截面径向剖面与一维"仅侧面"解在所有时刻吻合到 10⁻⁶（达标时刻差 2.6×10⁻⁷）；③ 退化测试：端面改绝热后逐格退回一维解，偏差 2×10⁻¹⁶；④ 端面通量恒等式：`t=0` 时含水速率比精确等于 `1+R/L`（理论 1.080/1.500/2.000 三组几何）；⑤ 与之对照的拟一维 `2h/L` 模型给出 35.2133 h，比二维真解短 **45.35%**；⑥ Newman 乘积解（独立解析路线）：问题1 `Fo_slab=0.0006`、问题2 `0.0093`，中截面轴向因子与 1 的差 <10⁻⁷；问题3 用 `D(C₀)`（最保守）估得轴向渗透 5.28 cm、占半长 42%，改用干态 `D` 只剩 1.3 cm、份额 <5%——**真值介于两者之间，常系数估计定不出来**。路径：`aproblem/axisymmetric.py`、`outputs/study/axisym_*/axisymmetric_scan.csv`、`docs/05` §5 |
| **文献支撑** | L-29（有限圆柱与无限圆柱的差别会**系统性改变**反演出的 `D_eff`，直接支持"几何口径必须声明"）、L-15（Newman 乘积解）、L-19/L-27（有限几何与共轭界面） |
| **强度** | Ⅰ（对称性）+ Ⅱ（二维数值，问题1/2/4）；问题3 尺度上目前只有 Ⅲ，见缺口 T3 |
| **论文落点** | 3.5 建模假设、8 验证与确认 |
| **边界与反例** | 结论的适用条件是"轴向渗透深度远小于半长"。问题1/2 由乘积解与二维双重证明；问题4 由二维证明；**问题3 尚未定量**（标定用 `D(C₀)` 的上界很松） |
| **缺口** | **T3**（问题3 端面影响定量） |

## G7　时间推进与事件定位

| 字段 | 内容 |
|---|---|
| **主张** | 主求解器为二阶显式 Heun（SSPRK2）；时间步由**节点局部总流出系数**动态给出稳定上限；终点事件用跨步线性插值定位，报告连续时刻而非离散步终点 |
| **类型** | 数学 + 数值 |
| **推导要点** | `λ_i = (Σ界面导通系数 + 侧面对流项 + 端面源项)/(容量项·V_i)`，`Δt ≤ safety/max λ`（safety=0.8），实际步长取 `min(Δt_cap, Δt_stable, 到下一输出时刻的剩余)`；Heun：`k1=F(t,y)`、`y*=y+Δt k1`、`k2=F(t+Δt,y*)`、`y_new=y+Δt(k1+k2)/2`；事件 `g(t)=max_i C_i − 0.15` 由正变非正时线性插值定位 `t*` |
| **计算证据** | ① 时间步收敛：问题4 `dt≤0.5/0.25/0.125 s` 三档达标时刻**完全相同**（35.2133 h，`outputs/study/time_convergence.csv`）；② 独立对拍：Heun vs SciPy BDF 相对差 6.4×10⁻⁷ / 2.3×10⁻⁷；③ 实测动态步长范围：问题4 midpoint N=40 为 `1.09×10⁻⁴～0.5 s`，kirchhoff N=40 为 `3.2×10⁻⁵～0.5 s`（通量势使界面系数更大、稳定步长更紧，运行时间约 +40%，属可接受代价）；④ 事件定位在人工线性 ODE 上验证 |
| **文献支撑** | L-08（SSP 时间离散）、L-10（BDF 原始文献） |
| **强度** | Ⅱ |
| **论文落点** | 6.3 时间推进、6.4 终止事件 |
| **边界与反例** | "二阶"不代表没有稳定性限制：扩散半离散仍需 `Δt ~ Δr²/D_max`，SSP 性质不能替代这一步检查 |
| **缺口** | — |
