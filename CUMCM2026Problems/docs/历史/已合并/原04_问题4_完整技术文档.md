## 1. 这份文档解决什么问题

问题 4 是整张 A 卷里唯一一个**几何会变**的问题：药材在烘干过程中
半径从 2.0 cm 缩到约 1.2 cm，网格所在的物理区域一直在缩小。
这件事同时带来三个麻烦：

1. **坐标怎么选**——网格钉在物理位置上就会被收缩的表面"扫出去"；
2. **物性怎么算**——附录 4 的扩散系数 `D(C,T)` 在干燥过程中跨越四个
   数量级，界面上取什么值直接决定答案；
3. **端面算不算**——圆柱长 25 cm、半径 2 cm，两个端面占 8% 表面积，
   不能一句"无限长"带过。

队友的原始版本（`AProblem/`）把前两件事用**一个 AI 估算、再用结果反推的
校准权重（`0.8705`）**糊了过去，第三件事用一句闭合假设带过且从未校验。
本文档记录我们把这三个问题各自换成**有依据、可复现、可检验**的处理方式
的全过程，以及由此得到的全部数字。

**一句话结论**：正式结果取**二维轴对称模型**（两个端面作为真实边界求解），
达标时刻 **51.1837 h**。界面扩散系数改用中点状态点值后，网格收敛性比原来
提高两个数量级；而原始方案里的端面等效源项把端面影响高估了约 45%，属于
会改变答案的模型误差，相应的一维结果已降为对照。

**本文只讲模型、代码和正式结果；所有对照算例、验证证据与敏感性分析见**
[`05_问题4_对照分析.md`](05_问题4_对照分析.md)。

## 3. 物理与数学模型

### 3.1 控制方程

圆柱坐标下，只保留径向（题目只要求到中心的距离），传热与传质耦合：

```
ρ(C)·cp(C)·∂T/∂t = (1/r)·∂/∂r( r·k(C)·∂T/∂r )
∂C/∂t            = (1/r)·∂/∂r( r·D(C,T)·∂C/∂r )
```

**为什么水分方程左边没有密度？** 严格写是 `∂(ρ_d C)/∂t = ∇·(ρ_d D ∇C)`，
`ρ_d` 是干基密度（每立方米有多少干物质）。不收缩时干物质既不动、体积也不变，
`ρ_d` 是常数，两边约掉。**收缩情形下 `ρ_d` 会变大，但下面 3.4 节会证明
它在材料坐标里恰好与几何缩放抵消，因此方程形式不变。**

### 3.2 边界条件与那个量纲陷阱

中心（r=0）：对称，`∂T/∂r = 0`，`∂C/∂r = 0`。

表面（r=R）：第三类（Robin）边界，

```
-k·∂T/∂r|_R = h·(T_R − T_air)      h  = 25 W/(m²·K)
-D·∂C/∂r|_R = h_m·(C_R − C_air)    h_m = 8×10⁻⁷ m/s
```

**量纲陷阱（全题第一大坑）**：`h_m` 单位是 m/s，它要配的浓度单位是
kg/m³；但题目给的 `C` 是 kg/kg（干基含水率）。必须两边同乘干基密度
`ρ_d` 才能约掉：

```
内部通量 = ρ_d · D · ∂C/∂r        [kg/m³ × m²/s × (kg/kg)/m = kg/(m²·s)] ✓
表面对流 = ρ_d · h_m · (C_R − C_air)  [kg/m³ × m/s × kg/kg = kg/(m²·s)] ✓
```

两边同时有 `ρ_d`，约掉后就是上面代码里的形式。这一步必须原样写进论文。

**4 h 之后的烘房条件**：附件 1 只到 14400 s。主方案假设之后进入恒温干燥
阶段，保持 50 ℃、0.05 kg/kg；并保留"保持附件末值"作为敏感性对照。

### 3.3 材料坐标：问题4 的关键一步

定义材料层坐标

```
ξ = r / R(t)          r(ξ, t) = ξ·R(t)
```

`ξ` 标记同一材料层，不随时间改变：圆心永远是 `ξ=0`，表面永远是 `ξ=1`。

**为什么不用固定空间坐标？** 固定网格会被收缩的表面扫过——第 20 个节点
本来在材料里，过一会儿就跑到材料外面去了。

**有没有多出来的"拖曳项"？** 取决于起点。

- 从**固定空间坐标**的方程 `∂C/∂t|_r = 扩散` 出发，变换后会出现
  `ξṘ/R · ∂C/∂ξ` 这一项；
- 从**材料导数**出发：

```
DC/Dt = ∂C/∂t|_r + v·∂C/∂r
      = (∂C/∂t|_ξ − ξṘ/R·∂C/∂ξ) + (ξṘ/R)·∂C/∂ξ
      = ∂C/∂t|_ξ
```

两项精确抵消，**没有额外拖曳项**。干基含水率本来就是跟随固体骨架的状态量，
所以材料坐标是更自然的起点。

**收缩下的几何缩放（均匀径向收缩）**：

```
节点间距 dr ∝ R      界面面积 A ∝ R
控制体体积 V ∝ R²    径向扩散项 ∝ 1/R²
```

代码不去用这些比例关系，而是**每个时间步按当前 `R(t)` 重建真实的控制体
几何（面积、体积、间距）**，两者等价但前者更不容易写错。

### 3.4 干物质守恒：为什么收缩不改变水分方程形式

设材料层 `ξ` 处的干物质密度为 `ρ_d(t)`。均匀收缩下体积 `V ∝ R²L`，
干物质守恒要求 `ρ_d ∝ 1/(R²L)`。该层的水量是 `ρ_d·C·V`，代入后
`∝ C`——与收缩无关。把守恒律在材料坐标里展开，`ρ_d` 的时变项与雅可比
变化精确抵消，最终得到

```
∂C/∂t|_ξ = (1/R²)·(1/ξ)·∂/∂ξ( ξ·D·∂C/∂ξ )
```

**这正是代码里那条方程，`ρ_d` 不出现。** 这一步是"为什么可以直接用题目
给的 `D` 而不需要额外密度信息"的严格依据。

### 3.5 端面：从二维方程降维，以及它的代价

圆柱有两个端面。把二维轴对称方程沿 `z ∈ [0, L]` 积分，端面的对流通量
折算成体积源项：

```
S_T = (2·h / L)·(T_air − T̄)
S_C = (2·h_m / L)·(C_air − C̄)
```

推导本身没问题（平均方程的源项确实是 `2h/L`），但**闭合时用了一个强假设**：

> 端面处的状态约等于同半径处的轴向平均状态：`C_end ≈ C̄`。

队友版本和我们的第一版都用了这个式子且从未校验它。**本项目的二维轴对称
模型就是为了校验它，结果发现它不成立**——详见第 7、8 节。

### 3.6 长度 L(t)：题目没给的部分

附件 2 只给半径，不给长度。长度是一个**无法由数据唯一识别**的量。

我们做了两件事：

1. 主方案取 `L = 0.25 m` 恒定，另做 `L ∝ R`（各向同性同步收缩）的敏感性；
2. 用题目自己给的密度公式做**干物质守恒自洽检验**，判断哪个假设与数据相容。

检验方法：附录 4 的 `ρ(C)` 是表观湿密度，换算成干物质密度

```
ρ_d(C) = ρ(C) / (1 + C)
```

干物质守恒要求每个材料层的体积收缩倍数唯一确定：

```
ρ_d(C_末)·V_末 = ρ_d(C_初)·V_初
```

于是可以用含水率剖面反推体积比 `V_末/V_初`，再与附件 2 给出的径向面积比
`(R_末/R_初)²` 对照，反推出长度比。**该检验不含任何自由参数。**

## 4. 数值方法

### 4.1 节点中心型有限体积法

半径方向切成 `N` 段，取 `N+1` 个节点（含圆心和表面）。节点 `i` 管一个
控制体，边界取相邻节点中点：

```
中心节点 i=0 ：一块半径 dr/2 的实心小圆盘
中间节点     ：半径 r_i、厚度 dr 的圆环
表面节点 i=N ：被表面切掉一半，只从 R−dr/2 到 R
```

**中心环和表面环只有半个厚度**，这是最常见的 bug；如果全部按 `r_i·dr` 算，
中心和表面的热容会算错一倍，整条温度曲线偏移。代码里有专门的单元测试
检查 `ΣV = πR²`。

环 `i` 的收支方程（以热为例，水分同构，只是去掉 `ρcp`）：

```
V_i·ρcp·dT_i/dt = G_{i−1/2}(T_{i−1}−T_i) + G_{i+1/2}(T_{i+1}−T_i) + 边界项
G_{i+1/2} = k_face·A_{i+1/2}/dr
```

**用有限体积法而不是直接差分的两个理由**：

1. 每个界面上"左格流出的"和"右格流入的"是同一个数，总量自动守恒；
2. 圆心 `r=0` 不需要特殊处理——它只是"没有内侧邻居"而已。若直接对
   `(1/r)·d/dr(...)` 做差分，`r=0` 处会除以零，还得用洛必达法则绕。

### 4.2 界面扩散系数：本项目最大的改动

`D(C,T)` 从 `C=2.55` 到 `C=0.05` 会掉 **4 个数量级**。表面先干、`D` 塌陷，
形成一层几乎不透水的"硬壳"，所以**界面上取什么值直接决定答案**。

我们实现了三套**有物理依据**的策略，并把选择权交给网格收敛性：

| 策略 | 公式 | 物理含义 |
|---|---|---|
| `midpoint` | `D(C_f, T_f)`，`C_f=(C_i+C_{i+1})/2` | 连续介质中点值，不引入分层假设 |
| `harmonic` | `2·D_i·D_{i+1}/(D_i+D_{i+1})` | 经典串联阻力，适合两层不同材料贴合 |
| `series` | `(r_{i+1}−r_i) / ( r_f·[ln(r_f/r_i)/D_i + ln(r_{i+1}/r_f)/D_{i+1}] )` | 圆柱径向串联阻力，含对数半径项 |

`series` 在等距平板极限下自动退化为调和平均，因此同一策略也能直接用于
二维模型的轴向界面；圆心那一格因为实心圆盘没有内侧界面、对数项在 `r=0`
发散，薄层极限下退回调和平均（有单元测试覆盖）。

**结果（问题 4，含端面，BDF 引擎）**：

| 界面策略 | N=20 | N=40 | N=80 | N=40→80 相对变化 |
|---|---|---|---|---|
| **midpoint** | 35.2503 h | 35.2132 h | 35.1971 h | **0.0458%** |
| harmonic | 39.8927 h | 36.1002 h | 35.3700 h | 2.0228% |
| series | 39.7687 h | 36.0886 h | 35.3691 h | 1.9937% |

**结论**：`harmonic` 与 `series` 几乎完全重合——它们同源，都把连续变化的
`D` 当成两层材料串联，等于在连续材料里人为插进一层不存在的分层阻力，
粗网格上严重高估传质阻力。`midpoint` 在 N=40 就已收敛到 0.05% 以内。

按事先定好的规则（相邻网格相对差 < 1%，多套都满足时取中点），
**主方案采用 `midpoint`，生产网格 N = 40**。

### 4.3 时间推进与动态稳定步长

主求解器是二阶显式 Heun（SSPRK2）：

```
k1 = F(t, y);  y* = y + Δt·k1;  k2 = F(t+Δt, y*)
y_new = y + Δt·(k1 + k2)/2
```

显式格式有稳定性上限。我们对每个节点计算"单位容量的总流出系数"

```
λ_i = (Σ界面导通系数 + 侧面对流项 + 端面源项) / (容量项·V_i)
Δt ≤ safety_factor / max_i(λ_i)          safety_factor = 0.8
```

实际步长取 `min(dt_cap, Δt_stable, 下一个输出时刻前的剩余时间)`。
**问题 4 里 `R(t)` 变小、物理格距随之缩小，所以稳定上限每个时间步都要重算。**

两个关键点：

- 稳定性估计与右端项**共用同一个界面策略对象**，不允许两处各写一份；
- 输出间隔 60 s 只是保存间隔，不是内部时间步。

### 4.4 干燥终点的事件定位

达标判据是"药材各处 `C < 0.15`"，即

```
g(t) = max_i C_i(t) − 0.15 由正变非正
```

代码每一步检查 `g` 的符号变化，跨越时用线性插值定位连续事件时刻
`t*`，避免只报告离散步的终点。注意**始终取全场最大值，不预设中心
一定是最慢点**。

### 4.5 二维轴对称模型（本项目的核心增量）

为了校验 3.5 节的闭合假设，我们实现了完整的二维轴对称材料坐标模型：

```
ξ = r/R(t)，η = z/L(t)

∂T/∂t = (1/(ξR²))∂_ξ(ξ·α·∂_ξ T) + (1/L²)∂_η(α·∂_η T)        α = k/(ρcp)
∂C/∂t = (1/(ξR²))∂_ξ(ξ·D·∂_ξ C) + (1/L²)∂_η(D·∂_η C)
```

（两个方向都跟随材料，因此同样没有拖曳项。）

边界：`ξ=0` 轴对称；`ξ=1` 圆柱侧面 Robin；`η=0, 1` 两个端面 Robin。
二维里端面是**真实边界**，不再需要 `2h/L` 这种降维近似。

控制体几何用真实物理面积和体积：径向界面面积 `2πr·Δz`，轴向界面面积是
环带横截面积 `π(r_out²−r_in²)`，端面节点控制半格 `Δz/2`。

时间推进同样是 Heun + 动态稳定步长；达标事件用**二维全场最大值**。
二维不做 BDF 对拍（状态量上千时有限差分雅可比不现实），改用
`dt` 与网格的双重收敛替代。

## 5. 代码结构与逐模块说明

```text
AProblemMaterial/
├── aproblem/
│   ├── __main__.py        命令行入口：组装配置、运行、导出
│   ├── config.py          路径与仿真配置（含界面策略/长度/边界延拓）
│   ├── data.py            附件读取、环境分段线性插值、半径 PCHIP 保形插值
│   ├── grid.py            圆柱径向控制体几何（三个几何因子、半控制体）
│   ├── physics.py         附录 2/3/4 三套物性，逐字段 + 整体两种接口
│   ├── interfaces.py      界面物性策略：midpoint / harmonic / series
│   ├── model.py           一维热湿有限体积 RHS + 端面等效源 + 稳定步长估计
│   ├── axisymmetric.py    二维轴对称材料坐标模型（端面校验）
│   ├── integrator.py      二阶 Heun、动态步长、连续事件定位
│   ├── crosscheck.py      SciPy BDF 独立时间积分
│   ├── outputs.py         预览文件 + 官方 result4.xlsx 导出（一维/二维两条通道）
│   ├── validation.py      物理范围检查 + result4 工作簿自动回读校验
│   ├── consistency.py     干物质守恒自洽检验（用于判定长度假设）
│   ├── study.py           批量研究驱动（界面扫描/网格/时间/敏感性/二维）
│   ├── report.py          汇总图表与验证报告
│   └── plotting.py        中文图表（剖面、演化曲线、二维热图、收敛曲线）
├── tests/                 29 项单元测试
└── outputs/               本地运行结果（已加入 .gitignore）
```

几个值得单独说明的设计：

**`physics.py` 提供逐字段接口。** 除了原有的 `evaluate()` 一次性返回四个
物性数组，还单独提供 `conductivity(T,C)` 和 `diffusivity(T,C)`。这样
`midpoint` 策略可以在面中点状态上调用**同一组公式**，不会出现两处写法
不一致。

**`interfaces.py` 沿最后一维操作。** 所有输入数组按"最后一维是节点方向"
约定，因此二维模型把径向转置一下就能复用同一套策略，不需要第二份实现。

**`scenarios.py` 拆成 `build_question()` + `run_question()`。** 组装与
积分分离，让收敛性研究可以对同一套模型自由选择 Heun 或 BDF。

## 7. 为什么正式结果取二维轴对称模型

3.5 节介绍的 `2h/L` 端面等效源项，其闭合假设是
"端面状态约等于同半径处的轴向平均状态"。我们为此单独实现了
二维轴对称材料坐标模型，把两个端面当作真实边界求解，用来校验它。

**校验结论：该闭合假设在本题几何下不成立。**

1. **几何尺度**：端面到轴向中截面有 `L/2 = 12.5 cm`，而轴向扩散
   在整个烘干过程中的穿透深度 `√(D·t)` 只有约 `0.8～2.1 cm`。
   轴向特征时间是径向的 `(L/2R)² = 39` 倍。
2. **对称性**：中截面的轴向通量恒为零，本不该获得端面带来的好处；
   而 `2h/L` 这个汇项被逐节点加到了每一个径向控制体上，包括中截面。
3. **判定点**：最后一个达标的点是中截面的圆心，因此它几乎完全由
   径向传输决定，其烘干时间等于"只有侧面"的时间。

数值证据：

| 支路 | 达标时刻 |
|---|---|
| 一维拟一维端面模型（`2h/L`） | 35.2133 h |
| **二维轴对称（真实端面）** | **51.1837 h** |
| 一维仅侧面模型 | 51.1837 h |

二维解在中截面上的径向剖面与一维"仅侧面"解在**所有时刻**吻合到
`10⁻⁶` 量级；两个独立做法给出同一个数，说明端面对达标时刻确实几乎
没有影响——这是物理事实，不是模型失效。

另外，题目自述烘干"一般持续 2–3 天"：`51.18 h = 2.13 天` 落在区间内，
`35.21 h = 1.47 天` 落在区间外。

因此正式结果取二维轴对称模型（沿轴向平均后映射到题目要求的固定物理
距离），一维拟一维端面模型降为对照。完整的对照数据、误差拆解和验证
证据链见 [`05_问题4_对照分析.md`](05_问题4_对照分析.md)。
