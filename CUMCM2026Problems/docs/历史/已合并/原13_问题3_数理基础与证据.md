## Q3-1　`D` 跨 3.8 个数量级：为什么界面取值是命门

| 字段 | 内容 |
|---|---|
| **主张** | 附录3 的 `D` 在干燥过程中跨越约 3.8 个数量级，全场极差约 6.8×10³ 倍、相邻界面 10²～10⁴ 倍；表面先干形成低渗透"硬壳"，因此界面取值直接决定干燥时长 |
| **类型** | 量级 + 数值 |
| **推导要点** | `D=2.4×10⁻³·e^{−0.45/C}·e^{−3850/T}`；50 ℃ 下 `D(2.55)=1.35×10⁻⁸`、`D(0.05)=1.98×10⁻¹²` m²/s |
| **计算证据** | ① 敏感性量级：一个固定权重从 0 变到 0.8705，可把"仅侧面"达标时刻从 70.46 h 拉到 51.09 h（**27.5%**）；② 对照问题1：同一套方法在问题1 里全场 `D` 只差 1.27 倍，换取法结果一字不变——**"重要"与"不重要"的判据是相邻面 `D` 的反差**。路径：`docs/03` §1.2、§1.3 |
| **文献支撑** | L-28（`D_eff` 随含水率/温度变化可达数量级）、L-16、L-18（实测内部剖面显示干壳效应） |
| **强度** | Ⅱ |
| **论文落点** | 2 问题分析、6.2 引言 |
| **边界与反例** | 若粗网格一格跨越整个干壳，任何取法都会失真；由 Q3-2 的网格扫描给出兜底 |
| **缺口** | — |

## Q3-4　固定加权平均在数学上不可能等价（校准权重的否证）

| 字段 | 内容 |
|---|---|
| **主张** | 若坚持用"算术平均与调和平均的凸组合"逼近真值，反解出的权重**不是常数**：它随含水率从 4.00 变到 0.61 并**跨越 1**。因此任何固定的 `w∈[0,1]` 都不可能在所有区间等于积分平均 |
| **类型** | 数学 + 数值 |
| **推导要点** | `D_w = w·A + (1−w)·H`，反解 `w=(I−H)/(A−H)`；附录3（50 ℃）下：`2.55→2.00` 得 `w=4.00`，`1.00→0.70` 得 `1.90`，`0.25→0.20` 得 `1.00`，`0.10→0.05` 得 `0.61`；同区间 `A/I` 从 0.998 涨到 1.584、`H/I` 从 0.998 跌到 0.069 |
| **计算证据** | 完整 11 行表格见 `docs/03` §5；权重跨越 1 意味着需要**外推**到凸组合之外。工程里出现的 `0.7247`（问题2/3）与 `0.8705`（问题4）是按过程平均的**拟合值**，不是物理常量——两者数值不同本身就说明这一点（真正由物理导出的常量不该换一套物性就重新标定） |
| **文献支撑** | L-01～L-04（通量势是物理量，不是拟合参数）；L-41（变系数扩散的积分平均） |
| **强度** | Ⅰ（不可能性结论） |
| **论文落点** | 6.2"为什么不能用一个权重"（一段即可） |
| **边界与反例** | 该否证针对"固定权重"这一类；若权重逐点求解到等于 `ΔΦ/ΔC`，那就已经退回通量势取法 |
| **缺口** | — |
