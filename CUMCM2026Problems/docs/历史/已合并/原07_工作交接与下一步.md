## 5. 已确定的模型结论

### 5.1 材料坐标

正式主模型采用：

```text
xi = r/R(t)
r(xi,t) = xi R(t)
```

`xi` 固定标记材料层，圆心始终为 `xi=0`，表面始终为 `xi=1`。

节点速度满足：

```text
v(r,t) = r dR/dt / R = xi dR/dt
```

所以不能说“每个节点等速度收缩”。正确说法是：各节点速度与半径成正比，圆心速度为 0，表面速度等于 `dR/dt`。

### 5.2 材料导数中没有额外拖曳项

固定物理位置下的 Eulerian 时间导数满足：

```text
partial C/partial t |_r
= partial C/partial t |_xi - xi (dR/dt)/R partial C/partial xi
```

材料导数为：

```text
DC/Dt
= partial C/partial t |_r
  + v partial C/partial r
= partial C/partial t |_xi
```

因此从材料坐标方程出发，不需要额外添加拖曳项。只有从固定空间坐标方程出发，才需要保留相应迁移项。

### 5.3 几何缩放

均匀径向收缩下：

```text
dr  proportional to R
A_radial proportional to R
V proportional to R^2
radial diffusion term proportional to 1/R^2
lateral Robin surface term proportional to A/V proportional to 1/R
```

### 5.4 正式模型和敏感性模型

正式主模型：

```text
均匀、各向同性的径向自由收缩
r = xi R(t)
```

敏感性模型：

```text
只引入一个归一化的非均匀形状函数 f(xi)
用于说明均匀收缩假设的不确定度
不写入正式 result4.xlsx
```

题目只提供外半径 `R(t)`，没有内部位移场，因此非均匀内部映射不可唯一识别。不能把敏感性模型写成已经被数据验证的物理事实。

## 6. 必须先纠正的概念：0.8705 不是端面参数

`0.8705` 出现在队友配置中：

```text
CUMCM2026Problems/AProblem/aproblem/config.py
question4_diffusivity_arithmetic_weight = 0.8705
```

它的实际作用是：

```text
D_face =
(1-w) * harmonic_mean(D_i,D_{i+1})
+ w * arithmetic_mean(D_i,D_{i+1})
```

其中 `w=0.8705`。

它只影响相邻径向节点之间的扩散系数，与端面的 Robin 换热、传质完全无关。

队友端面公式在另一段代码中：

```text
S_T,end = 2 h_T / L (T_air - T)
S_C,end = 2 h_m / L (C_air - C)
```

所以：

- 删除 `0.8705` 只解决径向界面扩散系数不严谨的问题。
- 删除 `0.8705` 不会自动解决端面建模问题。
- 端面需要单独的二维模型或明确的一维平均闭合。

## 7. 径向界面扩散系数的严谨公式

在圆柱径向坐标下，不能简单在所有界面使用算术平均，也不能靠权重校准。

设左节点半径为 `r_i`，右节点半径为 `r_{i+1}`，界面半径为 `r_f`，左右扩散系数分别为 `D_i`、`D_{i+1}`。串联扩散阻力为：

```text
Resistance
= (1/D_i) ln(r_f/r_i)
+ (1/D_{i+1}) ln(r_{i+1}/r_f)
```

由此得到等效界面扩散系数：

```text
D_face =
(r_{i+1}-r_i)
/
{
  r_f [
    (1/D_i) ln(r_f/r_i)
  + (1/D_{i+1}) ln(r_{i+1}/r_f)
  ]
}
```

物理原因：圆柱界面面积随 `r` 改变，所以径向串联阻力包含对数项。规则细网格下，该式趋近调和平均。

建议：

- 问题 4 删除 `0.8705`。
- 径向界面全部改用上式。
- 保留调和平均只作为细网格极限或数值对照。

## 8. 端面问题的严谨处理

### 8.1 为什么端面也要材料坐标

端面位于轴向位置，不是简单的径向边界。它上面的每一点仍有径向坐标：

```text
r = xi R(t)
```

随着药材半径收缩，端面的物理面积按照 `R(t)^2` 变化。只用一个固定的附加源，会丢失这种几何映射和端面附近的空间梯度。

### 8.2 推荐的主模型：二维轴对称材料坐标

定义：

```text
xi  = r/R(t),   xi in [0,1]
eta = z/L(t),   eta in [0,1]
```

均匀径向收缩、轴向均匀情况下，热量和水分方程可写成：

```text
rho cp partial T/partial t
= 1/(xi R^2) partial_xi(xi k partial_xi T)
+ 1/L^2 partial_eta(k partial_eta T)

partial C/partial t
= 1/(xi R^2) partial_xi(xi D partial_xi C)
+ 1/L^2 partial_eta(D partial_eta C)
```

边界条件：

```text
xi = 0      中心轴，对称
xi = 1      收缩后的圆柱侧面，Robin 换热和传质
eta = 0,1   两个端面，Robin 换热和传质
```

二维模型的优势：

- 端面附近先干、中部后干的轴向梯度可以自然出现。
- 端面面积、侧面面积、控制体体积都随 `R(t)` 正确变化。
- 不需要 `0.8705`。
- 不需要把端面失水强行平均到整个长度。

### 8.3 一维径向输出的定义

题目只要求给出到中心距离的结果。二维模型算完后，建议对轴向做平均：

```text
C_radial(xi,t) = integral_0^1 C(xi,eta,t) d eta
```

然后映射到物理距离：

```text
r = xi R(t)
```

达标事件必须使用二维全场：

```text
max over xi and eta of C(xi,eta,t) < 0.15
```

不能只看某个固定轴向截面。

### 8.4 现有拟一维端面源的地位

将二维方程沿 `z` 方向积分，并用同一半径处的轴向平均值近似端面值，可以导出：

```text
S_T,end = 2 h_T / L (T_air - T)
S_C,end = 2 h_m / L (C_air - C)
```

这不是随便拟合，但它包含较强的闭合假设：

```text
端面状态约等于该半径处的轴向平均状态
```

它忽略了端面附近和中部之间的轴向扩散阻力，因此可能高估端面影响。现有代码可以保留为降维对照，但不建议作为最终主模型。

## 9. 长度 L(t) 的关键未决问题
