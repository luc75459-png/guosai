## Q1-1　常物性使热方程与水分场解耦

| 字段 | 内容 |
|---|---|
| **主张** | 附录2 中 `ρ=820`、`cp=2600`、`k=0.36` 全为常数，且热方程中不含 `C`，因此温度场可由热方程单独求出，与水分场**完全解耦** |
| **类型** | 数学 |
| **推导要点** | `ρcp·∂T/∂t=(1/r)∂_r(rk∂_r T)`，系数均为常数 ⇒ 温度方程不含 `C`；水分方程中 `D(C)` 只依赖 `C` ⇒ 单向耦合（先解 `T`，再解 `C`） |
| **计算证据** | 问题1 采用附录2 时，界面取法从 midpoint 换成 Kirchhoff，**37800 个温度输出值无一格不同**（最大绝对差 0.000e+00）。路径：`docs/08` §2、§5.1；`outputs/问题1/{主模型_midpoint_N40,交叉验证_kirchhoff_N40}/result1.xlsx` |
| **文献支撑** | L-40（有限体积法基础）；L-41（变系数扩散） |
| **强度** | Ⅰ |
| **论文落点** | 5 通用模型（说明四问共用内核、只在物性与是否收缩上不同） |
| **边界与反例** | 该解耦只对附录2 成立；问题2/3/4 的 `k`、`ρcp` 依赖 `C`，必须双向耦合求解 |
| **缺口** | — |

## Q1-2　界面取法不影响问题1 的结果（逐格对照）

| 字段 | 内容 |
|---|---|
| **主张** | 问题1 换用基尔霍夫通量势后结果几乎不变：温度逐格相同，水分最大差 4.6×10⁻⁵（低于输出最低位的一半） |
| **类型** | 数值 |
| **推导要点** | 通量势要解决的问题是"相邻节点 `D` 相差悬殊"。问题1 在 1800 s 内全场 `D` 只变 **1.27 倍**、相邻界面最大相差 **2.8%** ⇒ 任何合理取法都给出几乎相同的界面值 |
| **计算证据** | ① 温度：37800 格全部相同；② 水分：最大绝对差 4.6×10⁻⁵、平均 3.2×10⁻⁶，四位小数下 1225/37800（3.24%）格点差 1 个单位；③ 论文表2 的 35 个采样点只有 2 个差 ±0.0001。路径：`docs/08_问题1_基尔霍夫势交叉验证.md`（逐格表）；两份结果文件均在 `outputs/问题1/` |
| **文献支撑** | L-03（通量势适用于连续渐变介质）、L-06（调和平均需真实分层）——本题两者都"用不上" |
| **强度** | Ⅱ |
| **论文落点** | 6.2 界面取值一节末尾（一句话交代即可） |
| **边界与反例** | **不要写成"因为差别不大所以随便选"**。正确表述是"经交叉验证的定量结论"：`D` 全场仅差 1.27 倍 ⇒ 该取法在本题不敏感 |
| **缺口** | — |

## Q1-3　端面在 30 分钟内来不及影响中截面

| 字段 | 内容 |
|---|---|
| **主张** | 问题1 的窗口远小于轴向扩散的特征时间，端面对中截面径向分布的影响在 10⁻⁷ 量级，可忽略；主结果按**中截面口径**报出 |
| **类型** | 解析上界 + 数值 |
| **推导要点** | 轴向渗透深度 `√(D·t)`：`D(2.55)=4.94×10⁻⁹ m²/s`、`t=1800 s` ⇒ **0.30 cm**，远小于半长 12.5 cm；`Fo_slab=D t/(L/2)²=6×10⁻⁴` |
| **计算证据** | ① **Newman 乘积解**：中截面轴向因子与 1 的差 **<10⁻⁷**，端面对体积平均的份额上界 0.84%；② **二维轴对称模型**：`t=1800 s` 时端面影响的轴向范围仅 1.62 cm，中截面径向分布与一维解的温度偏差 <10⁻⁷ ℃、含水率偏差为 0。路径：`四问结果汇总.md` §4.2、`docs/02` §8（降维误差检验项） |
| **文献支撑** | L-15（Newman 乘积解）、L-29（有限/无限圆柱会改变反演参数 ⇒ 需声明几何口径）、L-19（有限几何共轭模型） |
| **强度** | Ⅱ |
| **论文落点** | 3 模型假设（端面口径）、8 验证与确认 |
| **边界与反例** | 该结论只对"短窗口 + 低温差"成立；不能外推到问题3/4 的长窗口（那里的端面影响需单独判定，见 G4、T3） |
| **缺口** | — |
