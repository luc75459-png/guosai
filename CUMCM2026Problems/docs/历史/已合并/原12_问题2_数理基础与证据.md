# 12 问题2 数理基础与证据

> 问题2：前 3 小时（0～10800 s）的温度与含水率，物性取自附录3。
> 通用卡片见 [10 通用篇](10_数理基础_通用篇.md)；框架与缺口见 [09](09_论证框架与素材地图.md)。
> 完整公式见 [15 详卷（上）](15_推导详卷_通用模型与数值方法.md) §1.1、§2.1、§6.1 与
> [16 详卷（下）](16_推导详卷_端面与收缩.md) §1.3。

**本问一句话**：把物性从附录2 换成附录3 后，`ρ/cp/k` 开始依赖 `C`、`D` 依赖 `T`，
方程**双向耦合**；但 3 h 内场仍停在 `D` 变化平缓的湿区，所以界面取法依旧不敏感。

---

## Q2-1　变物性带来双向耦合，同步显式推进等价于全耦合

| 字段 | 内容 |
|---|---|
| **主张** | 附录3 中 `ρ=650+128C`、`cp=1450+2736C/(1+C)`、`k=0.21+0.38C/(1+C)`、`D` 含 `e^{−3850/T}`；温度与水分两个方程通过物性互相耦合 |
| **类型** | 数学 + 数值 |
| **推导要点** | 每个时间步用上一步的 `T` 算 `D`、用上一步的 `C` 算 `k`，即"同步显式推进"；当 `Δt` 足够小（本题动态稳定步长上限 `~10⁻⁴` s 量级）时，其离散误差低于时间离散本身，等价于全耦合牛顿迭代的一步 |
| **计算证据** | ① 时间步收敛与BDF 对拍（见 G7）；② 问题2 的 `N=160` 结果与队友独立实现在 `t=10800 s` 全部一致。路径：`docs/02` §5、`AProblem_方法定案.patch` 的核验段落 |
| **文献支撑** | L-16、L-22（耦合热质传递的建模与验证） |
| **强度** | Ⅰ（耦合关系）+ Ⅱ（数值等价性） |
| **论文落点** | 5 通用模型（物性表）、6.3 时间推进 |
| **边界与反例** | "同步推进 = 全耦合"依赖步长足够小；若用大固定步长（如 `dt=0.5 s` 且网格很细）则不再成立——这正是主模型改用动态稳定步长的原因之一 |
| **缺口** | — |

## Q2-2　界面取法在问题2 上换与不换几乎无差别

| 字段 | 内容 |
|---|---|
| **主张** | 问题2 换用基尔霍夫通量势后，末态温度差 2.4×10⁻⁵ ℃、含水率差 1.0×10⁻⁶，低于输出精度；仍切到通量势是为**四问口径统一**，代价为零 |
| **类型** | 数值 |
| **推导要点** | 3 h 内含水率只从 2.55 降到 0.94～1.65，全场都处在 `D` 随 `C` 变化平缓的湿区；相邻界面的 `D` 反差小 ⇒ 界面取法不敏感（与问题1 同因，但机理从"常物性"变成"仍在湿区"） |
| **计算证据** | N=80 上末态 `max` 温度差 2.4×10⁻⁵ ℃、`max` 含水率差 1.0×10⁻⁶。路径：`docs/03` §6.4 |
| **文献支撑** | L-03、L-41 |
| **强度** | Ⅱ |
| **论文落点** | 6.2 末段（用问题1、2 作为"取法敏感性依赖于场状态"的例证） |
| **边界与反例** | 不能把这条外推到问题3/4：那里的 `D` 跨 3～4 个数量级，取法差异可达 0.7% 以上并影响收敛阶 |
| **缺口** | — |

## Q2-3　端面判据：`Fo_slab=0.0093`，中截面轴向因子为 1

| 字段 | 内容 |
|---|---|
| **主张** | 3 h 的窗口内端面影响同样可忽略，主结果按中截面口径报出 |
| **类型** | 解析上界 |
| **推导要点** | `D(C₀)=1.35×10⁻⁸ m²/s`、`t=10800 s` ⇒ 轴向渗透 `√(Dt)=1.21 cm`（半长 12.5 cm）；`Fo_slab = Dt/(L/2)² = 0.0093` |
| **计算证据** | Newman 乘积解：中截面轴向因子与 1 的差 **<10⁻⁷**；端面对体积平均的份额上界 **4.4%**。路径：`四问结果汇总.md` §4.2 |
| **文献支撑** | L-15（乘积解）、L-29（几何口径影响反演参数） |
| **强度** | Ⅱ |
| **论文落点** | 3 模型假设、8 验证与确认 |
| **边界与反例** | 与问题1 相同：结论依赖"长窗口尚未使轴向渗透达到半长"，不可外推到问题3/4 |
| **缺口** | — |
