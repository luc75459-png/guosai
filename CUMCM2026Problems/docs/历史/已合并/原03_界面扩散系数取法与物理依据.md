## 0. 结论摘要

有限体积法把相邻两个节点之间的那个界面当成一个"闸门"，必须把两侧的扩散系数
`D(C_i)`、`D(C_{i+1})` 压成一个等效的界面值 `D_face`。本题的 `D(C,T)` 在干燥
过程中跨越约 2.6～3.8 个数量级，这个取值直接决定干燥时长，因此不能靠"曲线像
不像"来选。

本文档给出的结论是：

1. **调和平均与算术平均都不是本题的物理。** 它们分别对应"把 D 当成阶梯跳变"
   和"把 D 当成线性变化"两种**重构假设**，前者只在存在真实分层界面时成立，
   后者只在 D 沿路径近线性时成立。本题的 D 是连续、强非线性的，两种前提都不满足。
2. **通量守恒唯一确定了界面值：`D_face = ΔΦ/ΔC`，其中 `Φ(C)=∫₀^C D dc` 是
   基尔霍夫通量势（亦称基质通量势）。** 这不是一种"平均方式的选择"，而是一个
   恒等式，不含任何自由参数。
3. **三套附录的 D 都是 `A(T)·exp(−b/C)` 形式，因此 Φ 有初等解析原函数**
   `Φ(C) = A(T)·[C·e^{−b/C} − b·E₁(b/C)]`（E₁ 为指数积分），计算代价与一次
   指数运算相当，不需要数值积分。
4. **数值验证**：Φ 的解析式与独立数值积分一致到 10⁻⁶；`dΦ/dC = D` 逐点成立；
   网格收敛速度比中点点值快 15～33 倍；与队友独立实现的"积分平均"在三档网格上
   吻合到 4～5 位有效数字。
5. **常数加权平均在数学上不可能等价于通量势**：反解出的权重随含水率从 5.67
   变到 0.61 并跨越 1，因此任何 `w∈[0,1]` 的固定凸组合都无法复现它。

## 1. 界面取值为什么是本题的命门

### 1.1 D 的数量级跨度

三套附录给出的扩散系数在 50 ℃ 下分别为

| 附录 | 公式 | C=2.55 时 | C=0.05 时 | 跨度量级 |
|---|---|---|---|---|
| 附录2（问题1） | `7.0e-9·exp(−0.89/C)` | 4.94e-9 | 1.28e-14 | 5.6 个数量级 |
| 附录3（问题2/3） | `2.4e-3·exp(−0.45/C)·exp(−3850/T)` | 1.35e-8 | 1.98e-12 | 3.8 个数量级 |
| 附录4（问题4） | `4.2e-4·exp(−0.30/C)·exp(−3850/T)` | 2.50e-9 | 6.97e-12 | 2.6 个数量级 |

（附录3、4 的温度因子按 T = 323.15 K 计；附录2 不含温度项。）

问题的根源是 `exp(−b/C)`：含水率越低，扩散系数衰减越快。干燥过程中**表面先干、
扩散系数先塌陷**，形成所谓"硬壳（case hardening）"，热量和水分的传输因此被
强烈控制。

### 1.2 敏感性的量级

一个直接的对照：原工程用"调和平均与算术平均按 `w` 加权混合"这一个系数，`w` 从 0
变到 0.8705，就能把仅侧面工况的达标时刻从 70.46 h 拉到 51.09 h，**变化 27.5%**。

一个系数能拉动答案四分之一，它就必须来自推导而不是拟合。

### 1.3 但敏感性依赖于"反差"

必须强调一个前提：**界面取法重要，是因为相邻节点的 D 相差悬殊。**

| 问题 | 末态含水率范围 | 全场 D 极差 | 相邻界面 D 最大比值 |
|---|---|---|---|
| 问题1（1800 s） | 1.51 ～ 2.55 | **1.27 倍** | **1.03** |
| 问题2（3 h） | 1.01 ～ 2.55 | 约 20 倍 | 约 1.1 |
| 问题3（约 57 h） | 0.05 ～ 2.55 | **约 6.8×10³ 倍** | **10²～10⁴** |

同一个数值问题，在问题 3 里是千倍量级，在问题 1 里只有百分之几。这解释了为什么
后文对四个问题给出**不同**的结论（第 6.4 节）。

## 2. 三种经典界面平均的物理图像与适用边界

### 2.1 界面值的定义

控制体 i 与 i+1 界面的真实扩散通量（单位面积、单位时间）为

```
J = −D(C)·∂C/∂r
```

有限体积法把它写成两点格式

```
J_face = −D_face·(C_{i+1} − C_i)/Δr
```

`D_face` 就是需要确定的东西。三种经典答案对应三种重构假设：

| 取法 | 公式 | 等价的重构假设 | 正确的场合 |
|---|---|---|---|
| 算术平均 | `(D₁+D₂)/2` | 两层**并联**，或 D 沿路径**线性**变化 | D 沿路径近似线性 |
| 调和平均 | `2D₁D₂/(D₁+D₂)` | 两层**串联**（真实分层介质） | 存在真实的**物性间断** |
| 中点点值 | `D((C₁+C₂)/2)` | 对真实 D(C) 在区间中点做点值采样 | D 光滑、区间足够小 |

### 2.2 调和平均的适用条件是"真实分层"

调和平均之所以经典，是因为它在**分层介质串联**问题里是精确解：两块厚度相等、
扩散系数分别为 `D₁`、`D₂` 的平板贴合在一起，稳态串联通量算出来恰好是调和平均。
它的行为特征是**被两者中较小的那个支配**：当 `D₁/D₂ → ∞` 时，调和平均 `→ 2D₂`。

本题的 D 是**连续**变化的，不存在任何分界面。把调和平均用在连续变化的 D 上，
等价于人为插入一层不存在的分层阻力。当一层网格内 D 跨越 2～4 个数量级时，
这个假设造成的误差不是百分之几，而是数量级的（见第 6.1 节：问题 3 含端面工况
下，调和平均在 N=80 仍未收敛，N=40→80 的相对漂移高达 14.4%）。

### 2.3 算术平均的适用条件是"近线性"

算术平均 `(D₁+D₂)/2` 是对 `(1/ΔC)∫D dC` 的梯形求积近似，误差为
`−(ΔC)²D''(ξ)/12`。当 D 在区间内近似线性时它足够好；当 D 是强非线性
（`exp(−b/C)` 在低含水率区极陡）时，梯形规则会明显高估或低估。实测（附录3，50 ℃）：

| C 区间 | 算术平均 / 真值 |
|---|---|
| 2.55→2.00 | 0.998 |
| 0.35→0.25 | 0.993 |
| 0.15→0.10 | 1.073 |
| 0.10→0.05 | **1.584** |

即干壳区算术平均比真值高 58%，导致干燥偏快，结果从下方缓慢收敛。

### 2.4 中点点值是对通量势的二阶近似

`D((C₁+C₂)/2)` 是**中点求积法则**对 `(1/ΔC)∫D dC` 的近似，误差为
`+(ΔC)²D''(ξ)/24`，同样是二阶。实测（附录3）：

| C 区间 | 中点值 / 真值 |
|---|---|
| 2.55→2.00 | 1.001 |
| 0.35→0.25 | 1.003 |
| 0.15→0.10 | 0.963 |
| 0.10→0.05 | 0.699 |

在湿区它是三者中**最接近真值**的（0.1% 量级），这正是它在工程上表现良好的理论
原因；但在最干的几格里会低估 30%。它仍然是近似，不是恒等式。

### 2.5 本题的处境

本题的 D 既不是"两层串联"（调和），也不是"沿路径线性"（算术），更不是"区间
足够小到点值就够"（中点，因为干壳厚度远小于一格）。**本题需要的是那个精确量
本身**——这就把问题推给了第 3 节的通量守恒。

## 3. 通量守恒唯一确定的界面取法

### 3.1 推导

考虑无内源、稳态的一维通量。界面上没有任何物质累积，因此通过界面两侧的通量
处处相等：

```
Q = 2πr·D(C)·dC/dr = 常数
```

分离变量并从 `r_L` 积分到 `r_R`：

```
Q·∫_{r_L}^{r_R} dr/(2πr) = ∫_{C_L}^{C_R} D(C) dC
```

定义**基尔霍夫通量势**

```
Φ(C) = ∫₀^C D(c) dc
```

则精确通量为

```
Q = 2π·[Φ(C_R) − Φ(C_L)] / ln(r_R/r_L)
```

**它只依赖两端点的 Φ 值，与区间内 D 如何分布完全无关。** 这正是这个方法的价值：
不需要对 D 做任何重构假设。

### 3.2 与有限体积两点格式配对

有限体积法把同一个界面的通量写成

```
Q_fvm = 2π·r_f·D_face·(C_R − C_L)/Δr
```

令 `Q_fvm = Q`，解出

```
D_face = [Δr / (r_f·ln(r_R/r_L))] · (ΔΦ/ΔC)
```

方括号内是**纯几何因子**，与 D 的取值方式无关。在细网格极限下
`Δr/(r_f·ln(r_R/r_L)) → 1`，于是

```
D_face → ΔΦ/ΔC = (1/(C_R−C_L))·∫_{C_L}^{C_R} D dc        (★)
```

### 3.3 唯一性

给定两端点的 C 值，真实通量 `ΔΦ` 是唯一确定的；两点格式的通量
`D_face·ΔC/Δr` 也是唯一的。令两者相等，`D_face = ΔΦ/ΔC` 是**唯一解**。

换句话说：**如果要求两点格式在界面上与真实通量精确一致，`ΔΦ/ΔC` 是唯一可以取
的界面值。** 算术平均、调和平均、中点值都只是它的近似（分别是不同的数值求积法则）。

### 3.4 圆柱几何的对数因子（已知但未采用）

严格地说，(★) 式前面还有一个几何因子 `g_i = Δr/(r_f·ln(r_{i+1}/r_i))`。其量级为：

| 面序号 i | g_i − 1 |
|---|---|
| 1 | −3.82% |
| 2 | −1.35% |
| 3 | −0.68% |
| 5 | −0.28% |
| 10 | −0.08% |

即**只有最贴轴的几个面有影响，且随网格加密自动消失**（固定物理半径处的面序号随
N 增大而增大，因子趋于 1）。本工程所有策略都未施加该因子，属已量化的小量，
留作后续可选的细化解。

## 4. 本题三套附录的解析通量势

### 4.1 原函数

三套附录的 D 都有统一的形状

```
D(C, T) = A(T)·exp(−b/C)
```

其中 `A(T)` 对附录 3、4 还含 `exp(−3850/T)` 因子。做代换 `u = b/C`：

```
∫exp(−b/C) dC = C·exp(−b/C) − b·E₁(b/C) + const
```

推导：`dc = −(b/u²)du`，且 `∫e^{−u}u^{−2}du = −e^{−u}/u + E₁(u)`，
其中 `E₁(u) = ∫_u^∞ e^{−t}/t dt`。下限 C→0 时两项都趋于 0，因此

```
Φ(C, T) = A(T)·[ C·exp(−b/C) − b·E₁(b/C) ]
```

对 C 求导可直接验证 `dΦ/dC = D(C,T)`，即该原函数与题目给的扩散系数严格自洽。

### 4.2 三套附录的参数

| 附录 | A | b | 温度因子 |
|---|---|---|---|
| 附录2（问题1） | 7.0×10⁻⁹ | 0.89 | 无 |
| 附录3（问题2/3） | 2.4×10⁻³ | 0.45 | `exp(−3850/T)`，T 用 K |
| 附录4（问题4） | 4.2×10⁻⁴ | 0.30 | `exp(−3850/T)`，T 用 K |

### 4.3 数值验证

`tests/test_kirchhoff.py` 中包含三组自动验证：

1. **解析式 vs 数值积分**：对三套附录、多个含水率（0.05～2.55）与温度（28 ℃、
   50 ℃），解析 Φ 与 `scipy.integrate.quad` 一致到 `1e-5` 以内（实测最大相对
   偏差 2.3×10⁻⁶）。
2. **导数还原**：中心差分 `(Φ(C+h)−Φ(C−h))/(2h)` 与题目 D 公式一致到 `1e-4`。
3. **界面值 vs 独立积分**：`kirchhoff` 策略给出的界面值等于 `∫D dC/ΔC`
   （用 `quad` 独立算得），相对偏差 `1e-5` 以内。

此外还验证了：扩散系数为常数时通量势斜率精确退化为该常数；两侧含水率相等时
不出现 0/0；传热方程（无通量势）时退回中点值；一维与二维两条求解通道都能跑通。

## 5. 常数加权平均不可能等价于通量势

若坚持用"算术平均与调和平均的凸组合" `D_w = w·A + (1−w)·H` 去逼近真值 I，
可以反解出所需的权重 `w = (I − H)/(A − H)`。附录3（50 ℃）的结果如下：

| C 区间 | I = ∫D dC/ΔC | A/I | H/I | 反解 w |
|---|---|---|---|---|
| 2.55→2.00 | 1.3175e-8 | 0.998 | 0.998 | **4.00** |
| 2.00→1.50 | 1.2408e-8 | 0.997 | 0.995 | **3.22** |
| 1.50→1.00 | 1.1167e-8 | 0.992 | 0.986 | **2.47** |
| 1.00→0.70 | 9.4264e-9 | 0.992 | 0.983 | **1.90** |
| 0.70→0.50 | 7.5583e-9 | 0.991 | 0.975 | **1.54** |
| 0.50→0.35 | 5.5457e-9 | 0.990 | 0.954 | **1.29** |
| 0.35→0.25 | 3.5737e-9 | 0.993 | 0.930 | **1.11** |
| 0.25→0.20 | 2.1750e-9 | 1.000 | 0.951 | **1.00** |
| 0.20→0.15 | 1.2344e-9 | 1.010 | 0.880 | **0.92** |
| 0.15→0.10 | 4.5590e-10 | 1.073 | 0.640 | **0.83** |
| 0.10→0.05 | 5.6987e-11 | 1.584 | 0.069 | **0.61** |

两条结论：

1. **隐含权重不是常数**，它随含水率从 5.67 变化到 0.61。
2. **它跨越了 1。** 在 C > 0.25 的湿区，积分平均比算术平均还大，需要 `w > 1`，
   也就是要外推出调和平均与算术平均的凸组合之外。因此在数学上，**任何
   `w∈[0,1]` 的固定加权平均都不可能在所有区间等于积分平均。**

工程中出现的 `0.7247`（问题2/3）与 `0.8705`（问题4）不存在"完整推导"，原因不是
"没算"，而是**算不出来**：它们是按过程平均的拟合值，不是物理常量。两者的数值
不同本身就说明了这一点——真正由物理导出的常量不该因为换一套物性公式就重新
标定一次。

| **kirchhoff** | **57.5131 h** | **57.4830 h** | **57.4752 h** | **0.0137%** |

**含端面**（`2h/L` 等效源，仅作对照）：

| 界面策略 | N=20 | N=40 | N=80 | N=40→80 相对变化 |
|---|---|---|---|---|

#### 6.1.1 收敛阶与外推（判断取法是否正确的决定性证据）

把网格继续加到 N=160、320（问题3，不含端面，BDF），用自收敛公式
`p = log2(|f_N − f_2N| / |f_2N − f_4N|)` 估计观测收敛阶：

| 网格三重 | midpoint 观测阶 | kirchhoff 观测阶 |
|---|---|---|
| 20 → 40 → 80 | 1.157 | **1.928** |
| 40 → 80 → 160 | 1.260 | **1.941** |
| 80 → 160 → 320 | 1.383 | **1.948** |

| 方案 | N=20 | N=40 | N=80 | N=160 | N=320 | Richardson 极限 |
|---|---|---|---|---|---|---|
| midpoint | 58.50177 | 57.91126 | 57.64649 | 57.53597 | 57.49359 | 57.46724 h |
| kirchhoff | 57.51305 | 57.48304 | 57.47515 | 57.47310 | 57.47257 | **57.47238 h** |

三条读数：

1. **基尔霍夫的观测阶稳定在 1.93～1.95**，与"中心型有限体积 + 二阶面通量"的
   理论阶一致，说明它已进入渐近收敛区。
2. **中点的观测阶只有 1.16～1.38 且仍在爬升**，到 N=320 都未稳定，说明它的
   误差主项不是干净的二阶，粗网格上的结果不可用。
3. **两者的 Richardson 极限相差仅 0.005 h（0.009%）**，落在各自外推的不确定度
   之内——即两种离散**收敛到同一个连续解**。这正是"该格式是原方程的一致离散"
   的直接证据，排除了"收敛到另一个答案"的可能。

以基尔霍夫的 Richardson 极限（57.47238 h）为参考，同一网格上的相对偏差为：

| 方案 | N=20 | N=40 | N=80 |
|---|---|---|---|
| midpoint | 1.791% | 0.764% | 0.303% |
| **kirchhoff** | **0.071%** | **0.019%** | **0.005%** |

问题3 生产网格 N=40 的 kirchhoff 结果带有 `+0.011 h`（0.019%）的离散误差；
若论文需要更精确的点值，可报 N=80 或外推值。

### 6.3 跨实现交叉验证

队友工程 `AProblem` 用的是"积分平均"（即本文的 Φ 斜率），并采用"4 h 后保持附件
末值"的边界延拓。把我们的边界延拓调成同一口径后：

| 边界延拓 | 网格 | 队友"积分平均" | 本工程 `kirchhoff` | 差 |
|---|---|---|---|---|
| 保持附件末值 | N=20 | 57.209 h | 57.2099 h | +0.0009 h |
| 保持附件末值 | N=40 | 57.180 h | 57.1800 h | **0.0000 h** |
| 保持附件末值 | N=80 | 57.172 h | 57.1722 h | +0.0002 h |
| 固定 50 ℃/0.05 | N=80 | 57.472915 h | 57.4752 h | +0.0023 h |

**两套独立代码、两套独立实现，三档网格全部吻合到 4～5 位有效数字。** 这同时说明：
队友那个拟合权重实际上是在逼近积分平均，方向正确，只是把可推导的量做成了
待定系数。

### 6.4 问题1、问题2 的不同结论

**问题1：界面取法完全不影响温度，对水分的影响低于输出精度。**

| 对照（vs kirchhoff） | N | max 温度差 (℃) | max 含水率差 | 四位小数不同格数（共 37821 格） |
|---|---|---|---|---|
| midpoint | 40 | **0** | 4.59×10⁻⁵ | 0（温度）/ 1225（水分） |
| harmonic | 40 | **0** | 1.93×10⁻⁴ | 0 / 3942 |
| series | 40 | 1.12×10⁻³ | 1.79×10⁻⁴ | 19662 / 3856 |

温度**严格不变**的原因有两条：附录2 中 ρ、cp、k 全是常数，任何平均都得到同一个
数；而且问题 1 的热方程完全不含 C，与水分场解耦。唯一让温度变化的是 `series`
——它把圆柱的 `ln(r_f/r_i)` 几何因子也加进了导热系数的界面值，那是几何修正，
不是扩散系数平均的问题。

水分方面，问题 1 全场 D 只差 1.27 倍、相邻界面最大只差 2.8%，所以四种取法最大
只差 4.6×10⁻⁵ kg/kg，不到输出最低位（10⁻⁴）的一半。

因此**问题 1 沿用中点点值**，这不影响任何结论。

**问题2：换与不换几乎无差别。**

中点与基尔霍夫在 N=80 上的末态差异为 `max 温度差 = 2.4×10⁻⁵ ℃`、
`max 含水率差 = 1.0×10⁻⁶ kg/kg`。原因是 3 h 内含水率只从 2.55 降到 0.94～1.65，
整个场仍处在 D 变化平缓的湿区。仍然切到基尔霍夫，是为了方法口径统一，代价为零。

## 7. 工程实现

### 7.1 代码位置

| 文件 | 内容 |
|---|---|
| `aproblem/physics.py` | `flux_potential(T, C)`，解析式 Φ |
| `aproblem/interfaces.py` | `KirchhoffInterface`：`D_face = ΔΦ/ΔC`，ΔC→0 时用点值兜底 |
| `aproblem/model.py` | 一维水分方程传入通量势（传热侧不传） |
| `aproblem/axisymmetric.py` | 二维水分方程同样接入 |
| `aproblem/config.py` | 按题号默认策略：问题2/3 为 `kirchhoff`，问题1/4 为 `midpoint` |

**传热方程不适用通量势**：热流是 `k·∇T` 而不是 `k·∇C`，不存在关于 C 的势。
因此通用接口在传热侧不传通量势，策略退回中点值，与主方案保持一致。

### 7.2 代价

基尔霍夫算出的界面扩散系数比中点值大（干壳区可达 40% 以上），显式稳定步长因此
更紧：

| 工况 | 最小内部步长 |
|---|---|
| 问题4 / midpoint / N=40 | 1.09×10⁻⁴ s |
| 问题4 / kirchhoff / N=40 | 3.20×10⁻⁵ s |

单次运行时间约增加 40%（问题4 N=40 实测 150 s → 220 s），属可接受的代价。

## 8. 适用边界

1. 通量势的推导要求 **D 只随 C（在界面温度下）变化**。本题 D 还依赖温度，实现中
   取**面温度** `T_f` 上的 Φ，忽略了同一界面内温度沿路径的变化。由于热扩散比水分
   扩散快约两个数量级（特征时间约 40 min 对数十小时），界面内温差极小，该近似
   可以忽略。
2. 第 3.4 节的圆柱几何对数因子**未施加**，属已量化的小量。
3. 通量势只用于水分方程，传热方程仍用中点值。
4. 本文的方法学结论不依赖端面处理口径：端面只用 `2h/L` 等效源还是用二维轴对称
   真实边界，都不改变"水分界面应取 `ΔΦ/ΔC`"这一结论。
