## Q4-1　材料坐标与干物质守恒：`ρ_d` 为什么会消掉

| 字段 | 内容 |
|---|---|
| **主张** | 用材料坐标 `ξ=r/R(t)` 后，水分方程不出现干基密度 `ρ_d`，可以直接使用题目给的 `D` |
| **类型** | 数学 |
| **推导要点** | 严格式 `∂(ρ_d C)/∂t=∇·(ρ_d D∇C)`；均匀收缩下体积 `V∝R²L`，干物质守恒要求 `ρ_d∝1/(R²L)`，该层水量 `ρ_d·C·V ∝ C` 与收缩无关；把守恒律在材料坐标里展开，`ρ_d` 的时变项与雅可比变化精确抵消，得 `∂C/∂t|_ξ=(1/R²)(1/ξ)∂_ξ(ξ D ∂_ξ C)` |
| **计算证据** | ① 该式即 `AProblemMaterial/aproblem/model.py` / `axisymmetric.py` 实际求解的方程；② 几何自检：`ΣV` 对解析值到机器精度；③ 二维守恒闭合 2.1×10⁻¹⁵。路径：`docs/04` §3.4、`docs/06` §2 |
| **文献支撑** | L-17（圆柱+非各向同性收缩的热湿模型）、L-23（移动边界下必须一致处理收缩速度与 Jacobian）、L-20 |
| **强度** | Ⅰ |
| **论文落点** | 5 通用模型（收缩部分）／7.4 问题4 |
| **边界与反例** | 前提是"均匀、各向同性的自由径向收缩"；非均匀收缩（case hardening 引起的差异收缩）无法由外半径数据唯一识别，只能列入局限 |
| **缺口** | — |

## Q4-2　收缩的 R 标度：内部 ∝1/R²、侧面 Robin ∝1/R（本题唯一的"真 bug"陷阱）

| 字段 | 内容 |
|---|---|
| **主张** | 材料坐标下，**内部扩散项**与**表面 Robin 项**的几何标度不同：内部 ∝`(R₀/R)²`，表面 ∝`R₀/R`（因为表面积/体积 ∝`1/R`）。把两者混用会让表面失水被高估 `(R₀/R)²` 倍 |
| **类型** | 数学 + 数值 |
| **推导要点** | 节点间距 `dr∝R`、界面面积 `A∝R`、控制体体积 `V∝R²` ⇒ 径向扩散项 `∝1/R²`；侧面 Robin 通量走 `A/V∝1/R`。半径由 2.0 缩到 1.2 cm 时 `(R₀/R)²=2.78` |
| **计算证据** | ① **守恒性对拍**：材料坐标下的守恒量取 `W=ΣV_iC_i`（`V_i` 建在固定 `ξ` 网格上），理论上 `dW/dt=R₀²h_m(C_air−C_R)/R(t)`；修正前 `ΔW/累计通量` 在 1/6/24 h 为 **1.1172 / 1.4735 / 1.6873**（一路漂），修正后三档全部 **1.0000**（相对误差 10⁻¹⁴）；② 本工程采用"每步按当前 `R(t)` 重建真实控制体面积/体积"的写法，从结构上避免两套标度混用。路径：`问题4的改进.md` §一～二、`docs/05` §2 |
| **文献支撑** | L-23（移动边界中体积/雅可比与表面通量必须一致处理）、L-31（各向异性收缩的反例提醒） |
| **强度** | Ⅰ（标度关系）+ Ⅱ（守恒对拍） |
| **论文落点** | 5 通用模型（移动边界）、8 验证与确认（守恒性检验表） |
| **边界与反例** | 该结论的前提仍是"均匀径向收缩"；若长度同步收缩（敏感性工况），端面源项还要另乘长度方向的标度 |
| **缺口** | — |

## Q4-3　材料坐标下不应再加拖曳项

| 字段 | 内容 |
|---|---|
| **主张** | 干基含水率 `C` 跟随固体骨架定义，材料导数 `DC/Dt=∂C/∂t|_ξ`，坐标变换中的两个对流项精确抵消 ⇒ 材料坐标方程**不含额外拖曳项** |
| **类型** | 数学 |
| **推导要点** | `DC/Dt=∂C/∂t|_r+v·∂C/∂r=(∂C/∂t|_ξ−ξṘ/R·∂C/∂ξ)+(ξṘ/R)·∂C/∂ξ=∂C/∂t|_ξ` |
| **计算证据** | ① 主实现 `AProblemMaterial` 不引入该项（`model.py` 的注释与结构均如此）；② **量级对照**：在同一个求解器中打开/关闭该项，问题4 达标时刻由 50.69 h 变为 52.19 h（同标度、同网格、同界面取法），**差约 1.5 h（3%）**——说明这一项不是舍入量级，必须写清口径。路径：本轮补充计算（脚本见 `%TEMP%\q4verify`，属阶段性验证） |
| **文献支撑** | L-23（其 `v_s` 是**物理收缩速度**；映射到 `ξ=r/R(t)` 后是否出现拖曳项取决于变量定义，不能机械照抄）、L-17 |
| **强度** | Ⅰ（推导）+ Ⅱ（数值对照） |
| **论文落点** | 5 通用模型"移动边界"小节（用两行推导交代） |
| **边界与反例** | 只有当原始方程写在固定空间坐标、且不含固体速度时，才需要保留拖曳项。从**材料导数**出发的写法不需要——两种写法不能混用 |
| **缺口** | — |

## Q4-4　端面：`2h/L` 闭包被二维模型证伪

| 字段 | 内容 |
|---|---|
| **主张** | `2h/L` 体积源把两个端面的失水摊到**每一个**径向控制体（含中截面），而中截面按对称性轴向通量恒为零；二维真解表明端面对中截面几乎无影响，`2h/L` 把达标时刻压短约 45% |
| **类型** | 数值 + 对称性 |
| **计算证据** | ① 二维轴对称（端面真实 Robin）达标时刻 **51.1837 h**，与一维"仅侧面"解一致（差 2.6×10⁻⁷）；② 拟一维 `2h/L` 模型 **35.2133 h**，比二维真解短 **45.35%**；③ 二维网格 40×20 / 40×40 / 40×80 的达标时刻差 **1.6×10⁻⁸**；④ 退化测试：端面改绝热后逐格退回一维解（2×10⁻¹⁶）；⑤ 端面通量恒等式：`t=0` 时失水速率比精确等于 `1+R/L`。路径：`outputs/study/axisym_*/axisymmetric_scan.csv`、`docs/05` §5 |
| **文献支撑** | L-29（有限/无限圆柱会系统性改变参数反演 ⇒ 几何口径必须声明）、L-19、L-27 |
| **强度** | Ⅱ |
| **论文落点** | 7.4 问题4（端面口径）、8 验证与确认 |
| **边界与反例** | 这一条证明的是"**对中截面**端面可忽略"，不是"端面在所有位置都可忽略"——端面附近确实更干（末端轴向极差 0.088～0.093 kg/kg），这正是题目表格只要求径向分布时的口径选择依据。**注意：现行 `result4.xlsx` 导出的却是轴向平均剖面**（24 h、`r=0` 处 0.2681，而中截面是 0.2851），见缺口 **T9** |

## Q4-5　长度 `L(t)`：用干物质守恒做无自由参数的判定

| 字段 | 内容 |
|---|---|
| **主张** | 附件2 只给半径、不给长度。用附录4 的 `ρ(C)` 换算干基密度做自洽检验，可以在**不含任何自由参数**的前提下判定"长度近似不变"与数据相容，"各向同性同步收缩"与数据冲突 |
| **类型** | 数值（数据自洽检验） |
| **推导要点** | `ρ_d(C)=ρ(C)/(1+C)`；干物质守恒要求 `ρ_d(C末)·V末=ρ_d(C初)·V初` ⇒ 体积比 `V末/V初` 可由含水率剖面反推，再与附件2 的径向面积比 `(R末/R初)²` 对照，反推长度比 |
| **计算证据** | 初态干密度 278.73 kg/m³，末态 672.61～726.52 kg/m³；体积比 0.4043；附件2 面积比 0.3600 ⇒ 反推 **`L末/L初=1.1231`**：长度不变的相对偏差 **+12.3%**，各向同性同步收缩的偏差 **+87.2%**。故主线取 `L=0.25 m` 恒定，并把同步收缩作为敏感性上界：**30.3126 h（−13.92%）**。路径：`docs/05` §7、§8；`outputs/study/sensitivity.csv` |
| **文献支撑** | L-31（各向异性收缩的存在性）、L-23（收缩与体积/密度的闭合） |
| **强度** | Ⅱ |
| **论文落点** | 3 模型假设、9 不确定度（这一条是问题4 最大的不确定度来源） |
| **边界与反例** | 长度是"无法由数据唯一识别"的量；该检验给出的是**相容性区间**，不是唯一解。论文必须给出 ±14% 的区间并说明其来源 |
| **缺口** | — |

## Q4-6　主动指出题给数据的内部矛盾（13.4%）

| 字段 | 内容 |
|---|---|
| **主张** | 附录4 的 `ρ(C)` 与附件2 的 `R(t)` 不能同时严格成立：同时采用会让干物质总量凭空少 13.4% |
| **类型** | 数值（数据一致性） |
| **推导要点** | `M_dry∝ρ_d·R²`；`ρ_d` 由 278.7 涨到 672.6 kg/m³，半径比平方 0.3588 ⇒ `M_d,末/M_d,初=672.6/278.7×0.3588=0.866`。反之若要求干物质守恒，末态半径应为 1.287 cm，而附件2 给的是 1.198 cm（差 7%） |
| **计算证据** | 全部数字见 `docs/05` §8；`AProblemMaterial/aproblem/consistency.py` 提供该检验的实现 |
| **文献支撑** | L-23、L-31（真实材料收缩与密度变化的闭合关系） |
| **强度** | Ⅱ |
| **论文落点** | 9 误差与不确定度（"模型形式不确定度"一类） |
| **边界与反例** | 这不是我们能"修"的问题，而是题给参数集本身的不自洽。处理方式：主模型以附件2 的 `R(t)` 为准（题目明确要求用它描述收缩），把 13.4% 作为模型形式不确定度定量记录；**不要**悄悄改任何一个参数 |

## Q4-7　界面取法：问题4 也应统一到基尔霍夫（含现行口径与待收口）

| 字段 | 内容 |
|---|---|
| **主张** | 通量势取法与收缩、材料坐标完全兼容（`D_face=ΔΦ/ΔC` 是通量守恒的恒等式，与坐标是否移动无关）；数据上也表明问题4 应统一到 `kirchhoff` |
| **类型** | 数学 + 数值 |
| **推导要点** | 通量势只涉及"界面两侧 `C` 与面通量的配对"，与几何是否随时间变化无关。收缩只改变物理面间距（随 `R` 变小），不改变配对关系 |
| **计算证据** | 一维"仅侧面"达标时刻：`midpoint` N=40 / N=80 = **51.1837 / 51.1209 h**（外推 ≈51.100 h）；`kirchhoff` N=40 / N=80 = **51.0967 / 51.0895 h**（外推 ≈**51.0871 h**）。三条独立线索在同一数值上会合：本文 `kirchhoff` 外推 51.0871 h、队友独立实现的理查森外推 **51.087020 h**、以及队友原工程中按参考值反标定的 **51.087074 h**——**相差 0.4 秒以内**。路径：本轮补充计算（`python -m aproblem --question 4 --intervals 80 --interface-strategy kirchhoff`）、`问题4的改进.md` §三 |
| **文献支撑** | L-03、L-04（通量势适用于连续渐变与非线性扩散）、L-41 |
| **强度** | Ⅱ（数值一致性）／Ⅰ（兼容性论证） |
| **论文落点** | 6.2（说明四问统一）、7.4 问题4 |
| **边界与反例** | ① 现行交付（`result4.xlsx`）仍是 `midpoint` + 二维模型（51.1837 h），与一维 `kirchhoff` 的 51.0895 h 相差 0.09 h（0.18%）——**两者不能同时出现在论文里**；② 切换后必须重跑二维并重做"二维中截面 = 一维仅侧面"的交叉验证，否则该验证的口径断裂；③ 通量势算出的界面系数更大（干壳区可达 +40%），显式稳定步长更紧、运行时间约 +40% |
| **缺口** | **T1 / T8**：用 `kirchhoff` 重跑二维 40×20 / 40×40 / 40×80，重出 `result4.xlsx` 与验证报告；并同步更新 `docs/04`、`docs/05` 中所有以 51.1837 h 为结论的表述 |
