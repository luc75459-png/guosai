## 一、第一步：把圆柱切成一圈圈的环

药材是半径 2 cm 的圆柱。我们不关心长度方向（L/R = 12.5，够长，可当无限长），也不关心角度方向（各向同性），**只关心"离中心多远"**。所以问题是一维的。

把半径方向切成 N 段。取 N = 20 时，每段 dr = 0.1 cm，得到 21 个节点：

```
节点:   0     1     2    ...              19    20
r/cm:  0.0   0.1   0.2   ...             1.9   2.0
        ●─────●─────●─────●───  ...  ──●─────●
       中心                                  表面
```

每个节点管一个"环"（控制体积）。**这里有三个必须写对的几何量：**

**(a) 环的体积。** 环 i 从 `r_i − dr/2` 到 `r_i + dr/2`，体积 = 2π·r_i·dr·L。
我们把所有公式里都会出现的 `2π·L` 约掉，只留几何因子：

- 中心环（i=0）：它不是环，是一个半径 dr/2 的**实心小圆盘**，因子 = `(dr/2)²/2`
- 中间环（0<i<N）：因子 = `r_i · dr`
- 表面环（i=N）：它被表面切掉了一半，只从 `R−dr/2` 到 `R`，因子 = `(R² − (R−dr/2)²)/2`

> ⚠️ **中心环和表面环只有半个厚度。** 这是最常见的 bug——如果全部按 `r_i·dr` 算，中心和表面的热容会算错一倍，温度曲线整体偏移。

**(b) 界面的面积。** 环 i 和环 i+1 之间的那个圆柱面，面积 = 2π·r_{i+1/2}·L，因子 = `r_{i+1/2}`。

> **为什么圆柱坐标里到处是 r？** 因为越往外，圆周越长，同样的"温度梯度"能输运更多的热。这就是方程里 `(1/r)·d/dr(r·k·dT/dr)` 那个 r 的物理意义。用控制体积法你不用背这个公式，它自动就出来了。

**(c) 最外表面的面积**，因子 = `R`。

对应代码：`core/grid.py`，一共 20 行。

## 二、第二步：写出一个环的"收支方程"

这是有限体积法的全部思想，用一句话说：

> **这个环里的东西，一步之内多了多少 = 从内侧流进来的 − 从外侧流出去的。**

像记账一样。因为每个界面上"A 流出的"和"B 流入的"是同一个数，总量自动守恒，一分钱都不会丢。

对热量，环 i 的收支：

```
体积 × 密度 × 比热 × (温度变化率)  =  内侧界面流入的热  −  外侧界面流出的热

V[i] * rho * cp * dT[i]/dt = A[i-1/2]*k[i-1/2]*(T[i-1]-T[i])/dr
                           + A[i+1/2]*k[i+1/2]*(T[i+1]-T[i])/dr
```

每一项的意思：`(T[i+1]-T[i])/dr` 是温度梯度，乘以导热系数 k 得到"每平方米流多少"，再乘面积 A 得到"总共流多少"。

对水分完全一样，只是把 `k` 换成 `D`，并且左边没有 `rho·cp`：

```
V[i] * dC[i]/dt = A[i-1/2]*D[i-1/2]*(C[i-1]-C[i])/dr + A[i+1/2]*D[i+1/2]*(C[i+1]-C[i])/dr
```

> **为什么水分方程没有 rho？** 严格写是 `d(ρ_d·C)/dt = div(ρ_d·D·grad C)`，ρ_d 是干基密度（每立方米有多少干物质）。不收缩时干物质既不动、体积也不变，所以 ρ_d 是常数，两边约掉。**这一条要写进论文的假设里。**

**中心节点（i=0）不需要特殊处理。** 它内侧没有邻居，就是没有流入项，仅此而已。这正是控制体积法的好处——如果你直接对 `(1/r)·d/dr(...)` 做差分，r=0 处会除以零，还得用洛必达法则绕，很容易写错。

对应代码：`core/fvm.py` 的 `step()` 函数，传热和传质各 5 行。

## 三、第三步：两个边界

**中心（r=0）：** 对称，没有东西流进流出。上面说了，什么都不用写。

**表面（r=R）：** 热风把热送进来、把水汽带走：

```
流入的热   = A_R * h   * (T_air - T[N])        h  = 25 W/(m²·K)
流出的水   = A_R * h_m * (C[N] - C_air)        h_m = 8e-7 m/s
```

`T_air(t)` 和 `C_air(t)` 从附件1 读，线性插值到任意时刻（`core/boundary.py`）。

> ⚠️ **全题第一大坑：h_m 的量纲。**
> h_m 的单位是 m/s，它要配的浓度单位是 kg/m³。但题目给的 C 是 **kg/kg（干基含水率）**，两者不是一回事。
>
> 正确做法：把两边都写成"每平方米每秒流走多少 kg 水"。
> - 药材内部的水分通量 = `ρ_d · D · dC/dr`  （kg/m³ × m²/s × (kg/kg)/m = kg/(m²·s) ✓）
> - 表面对流通量 = `ρ_d · h_m · (C_R − C_air)`  （kg/m³ × m/s × kg/kg = kg/(m²·s) ✓）
>
> 两边同时有 ρ_d，约掉后就是代码里那个形式。**这一步的推导必须原样写进论文**，它证明你们知道自己在做什么。

> **另一条假设：4 小时以后怎么办。** 附件1 只给到 14400 s。之后进入"恒温干燥阶段"，我们假设烘房条件保持在 4h 末的值（50 °C，0.05 kg/kg）不变。代码里 `OvenCondition` 有个 `hold_after_end` 开关，方便做敏感性分析。

## 四、第四步：让时间往前走

最简单的办法（也就是你们去年用的显式欧拉）：

```
新的 T = 旧的 T + dt × (收支/热容)
```

一行代码。问题只有一个：**dt 不能太大**。

**稳定性条件的直觉：** 一步之内，"信息"不能跑过一个格子。热扩散在时间 dt 内能传播的距离约为 `√(α·dt)`（α = k/(ρcp) 叫热扩散率）。要求它小于格距 dr，就得到

```
α · dt / dr²  ≤  0.5           →     dt ≤ 0.5 · dr² / α
```

**代入本题的数：** α ≈ 2×10⁻⁷ m²/s，dr = 10⁻³ m
```
dt ≤ 0.5 × (10⁻³)² / (2×10⁻⁷) = 2.5 s
```

**好消息：题目要求的输出步长就是 1 s，本来就在稳定范围内。**

> 🎉 **所以这道题根本不需要隐式格式。** 我上一份文件里说问题3 要用隐式 + 自适应步长——那是保守过头了。实测：显式欧拉在 dr=0.05 cm、dt=0.4 s 下跑完 56 小时只要 **20 秒**。你们可以把"实现隐式格式"这一项从计划里划掉，省下整整一天。
>
> 唯一要注意的是：**dt 要随 dr² 缩小**。网格加密一倍，dt 要缩到四分之一。代码里 `max_dt()` 帮你算。

对应代码：`core/fvm.py` 的 `max_dt()` 和 `step()` 最后两行。

## 五、第五步：界面上的 D 取多少？（这一步决定答案对不对）

节点 i 上的 D 和节点 i+1 上的 D 不一样（因为含水率不一样）。**它们中间那个界面上该用多少？**

这在别的题里是个无关紧要的细节。**在这道题里它决定答案是 56 小时还是 500 小时。**

原因：`D = 2.4e-3 · exp(−0.45/C) · exp(−3850/T)`。当 C 从 2.55 降到 0.05，D 掉了 **4 个数量级**。表面先干，D 塌陷，形成一层几乎不透水的**硬壳（case hardening）**。

两种取法：

| 取法 | 公式 | 效果 |
|---|---|---|
| 调和平均 | `2·D₁·D₂/(D₁+D₂)` | 结果被两者中**小**的那个支配 |
| 算术平均 | `(D₁+D₂)/2` | 两者的平均 |

调和平均在物理上是为**分层介质**准备的（想象两块材料贴在一起，就像两个电阻串联，总电阻由大的那个主导）。但本题 D 是**连续变化**的，不存在真实的分界面。用调和平均等于人为插进一道不存在的密封层。

**实测对比（问题3 的烘干时长）：**

| 取法 | dr=0.1 cm | dr=0.05 cm | 是否收敛 |
|---|---|---|---|
| 调和平均 | > 500 h | > 72 h（还在漂） | ❌ 不收敛 |
| **算术平均** | **56.2 h** | **56.7 h** | ✅ 收敛，且符合题面"2–3 天" |

**结论：用算术平均。** 我上一份文件里推荐调和平均是错的，已经改了。

（如果你们后面还有余力，最优做法是 **Kirchhoff 变换**：令 `Φ(C) = ∫D dC`，则通量精确等于 `−dΦ/dr`，根本不需要在界面上平均 D。这是可选的加分项，**不做也完全能交出正确答案**。）

对应代码：`core/fvm.py` 的 `_interface()`。

## 六、第六步：验证（这一步花 30 分钟，能省你们两天）

写完求解器不要急着跑问题1。**先跑这三个检验**（`verify/checks.py`，已全部通过）。

### 检验 1：集总极限 —— 最强的一个，务必先过

**做法**：人为把 k 和 D 调大，让内部阻力可以忽略，整个圆柱变成一个等温等湿的"点"。这时它必须服从一个**能手算的**指数衰减：

```
dT/dt = h·A/(ρ·cp·V) · (T_air − T)，   圆柱的 A/V = 2/R

⇒  时间常数 τ_T = R·ρ·cp/(2h) = 0.02×820×2600/(2×25) = 852.8 s
⇒  水分同理 τ_C = R/(2·h_m)     = 0.02/(2×8e-7)      = 12500 s
```

**为什么这个检验这么强？** 因为它同时验证了四件事：体积因子 V、面积因子 A、边界条件、单位换算。数值解反推的时间常数对不上解析值，bug 就一定在这四项里，范围极小。

我跑出来的结果：
```
温度 时间常数: 解析  852.80 s   数值  855.37 s   偏差 0.302%
水分 时间常数: 解析 12500.00 s  数值 12665.01 s  偏差 1.320%
等温性(最大温差): 1.5e-02 °C
```
（残余偏差 ≈ Bi/4，是因为 k 不能真的取无穷大——否则显式格式的 dt 会被压到不可用。取 Bi=0.01 已经足够。）

### 检验 2：质量守恒

含水量的减少，必须精确等于从表面流出去的累计通量。这是控制体积法的天然性质，误差应该在机器精度量级。实测 **2.6×10⁻¹⁵** ✓

如果这一项不过，说明你的收支方程写错了（比如某个界面的流出没有对应到邻居的流入）。

### 检验 3：网格收敛

网格加密一倍，答案应该基本不变。实测（24h 后的中心含水率）：
```
N=10 (dr=0.20cm)  C=0.23614
N=20 (dr=0.10cm)  C=0.23661    差 0.00046
N=40 (dr=0.05cm)  C=0.23688    差 0.00028
```
差值在缩小 → 收敛 ✓。**这张表要放进论文**，是数值可靠性的直接证据。

> **问题1 有个结构性简化值得写进论文：** 附录2 里 ρ、cp、k 全是常数，D 只依赖 C。这意味着**热方程完全不含 C，可以先独立解出 T(r,t)，再解 C**。到问题2 换成附录3，k、ρ、cp 依赖 C 而 D 依赖 T，才真正双向耦合。点出这个层次，说明你们看懂了出题人的设计。

## 八、第八步：问题4 的移动边界（朗道变换）

这是唯一一个真正新的技术点。用一个比喻就能理解。

**问题在哪：** 药材在收缩，半径从 2.0 cm 缩到 1.2 cm。如果网格钉死在物理位置上，外边界会一路"扫过"网格点——第 20 个点本来在材料里，过一会儿就跑到材料外面去了。非常难处理。

**解决办法：换一把会跟着缩的尺子。** 定义

```
ξ = r / R(t)
```

ξ = 0 永远是中心，ξ = 1 永远是表面。**在 ξ 坐标里，网格不动了。**

**代价是什么：** 想象你在一根正在缩短的橡皮筋上画了 21 个等分点。这些点在橡皮筋上的位置（ξ）不变，但它们在空间中的实际位置一直在往里移。所以站在某个固定的 ξ 上观察，你看到的含水率变化 = 真正的扩散 + "点在材料里移动"带来的表观变化。后者就是多出来的**拖曳项**：

```
dC/dt |_ξ  =  (ξ·Ṙ/R)·dC/dξ   +   (1/R²)·[扩散项]
              └── 拖曳项 ──┘        └── 原来的扩散, 只是长度缩短了 ──┘
```

两处细节：
- **扩散项要除以 R²**：扩散强度 ∝ 1/长度²，材料变短了，同样的浓度差产生更大的通量。代码里就是那个 `s2 = (R0/Rt)²`。
- **拖曳项用迎风差分（后差）**：Ṙ < 0（在缩），信息从内向外传，用 `(C[i]−C[i−1])/dξ`。用中心差分会产生数值振荡。

**R(t) 从哪来：** 附件2 给了 145 个点（0–72 h，每 1800 s）。用 **PCHIP（保形插值）** 而不是普通三次样条——普通样条在数据平台段会过冲，产生虚假的 Ṙ > 0（药材变胖），物理上不成立。求导得到 Ṙ(t)。（`core/shrink.py`）

**输出的坑：** 题目要"到中心距离每隔 0.1 cm"，但 R(t) 在缩。超出 R(t) 的位置**没有材料**。表6 单独留了「药材表面」一列，就是因为出题人知道这件事。做法：把 ξ 网格上的解插值到固定物理网格 0, 0.1, …, 2.0 cm，超出表面的格子留空，并在论文里说明。

**自检项：问题4 的时长必须明显短于问题3。** 两个原因：收缩使 R² 缩小约 2.8 倍；附录4 的 D 在低含水率区比附录3 大约 3.5 倍，硬壳没那么致密。实测 **50.99 h < 56.71 h** ✓。如果你们算出问题4 更长，一定有 bug。
