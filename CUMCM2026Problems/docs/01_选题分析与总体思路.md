## 三、推荐：A 题，理由

1. **能力迁移几乎是 1:1 的。** 去年你们做的是"太阳几何 → 热流边界条件 → 热网络 ODE → 时间推进 → 验证"。A 题做的是"烘房温湿度 → 对流边界条件 → 传热传质 PDE → 时空推进 → 验证"。工作流完全相同，只是把 0 维集总换成 1 维径向、把 ODE 换成 PDE。**你们不需要学新范式，只需要把已有范式做深一级。**

2. **A 题所有结果都能自己验证，这是你们的强项也是拿高分的关键。** 常物性情形有 Bessel 级数解析解可对拍；有限体积法可查全局质量守恒；可做网格/时间步收敛性分析。去年你们已经展示了强烈的"验证意识"（雷暴日对照、气候对照组），这套东西在 A 题上能直接转化成评分点。

3. **A 题不依赖任何外部基础设施。** 没有登录、没有次数限制、没有 9/13 17:30 这种额外死线。剩下 4 天全部是可控的自有时间。

4. **物理洞察的空间大，而这正是去年那篇论文最亮的部分。** 下面第四节给了两个可以直接写进摘要的量纲分析结论——这类"从数字里读出机理"的段落，是你们去年拿分的方式。

**什么情况下改选 C：** 队里有人熟练用过 `scipy.linprog` / `PuLP` / `Gurobi` 且能在半天内搭出全年滚动回测框架，同时对"报童模型分位数"这类随机优化概念不陌生。否则 C 题会退化成"把 LP 写对了但第 2、3、4 问都在硬凑"，而这三问才是拉分点。

**什么情况下才碰 B：** 队里有一名可以**今晚就把模拟器跑通、明天中午前完成一次演练测试**的专职工程手，且团队接受"3 次正式机会 + 硬截止"的风险。B 题的建模部分（半平面交、信息增益驱动搜索）其实很漂亮，但成绩单是硬指标，跑不出来就是零。

## 四、A 题：完整建模思路

### 4.0 先做两个量纲分析（先做这个，会决定所有建模决策）

**传热 Biot 数：** `Bi_h = hR/k = 25 × 0.02 / 0.36 ≈ 1.39`

→ O(1)，内外热阻相当。**不能用集总参数模型**（这与你们去年式(6)的单节点假设正好相反，论文里可以显式对比说明"为何本题必须做空间离散"）。

**传质 Biot 数：** `Bi_m = h_m R / D ≈ 8×10⁻⁷ × 0.02 / 5×10⁻⁹ ≈ 3×10³`

→ **≫1，整个干燥过程由内部扩散控制**，表面含水率会迅速趋近于与烘房的平衡值。推论：表面 D 因 `D = 7×10⁻⁹ e^(-0.89/C)` 急剧塌陷（C 从 2.55 降到 0.15 时 D 变化约 **4 个数量级**），形成 **表面硬壳（case hardening）** ——这是可以写进论文的物理机理。

**特征时间对比：**
- 热扩散：`τ_T = R²/α = (0.02)² / 1.69×10⁻⁷ ≈ 2400 s ≈ 40 min`
- 质扩散：`τ_C = R²/D ≈ 10⁴ ~ 10⁵ s ≈ 数十小时`
- `Le = α/D ≈ 35`

→ **两个时间尺度差约 100 倍。这解释了整道题的结构**：问题 1（30 min）本质是传热问题，水分几乎没动；问题 3/4（数十小时）本质是传质问题，温度早已准平衡。摘要里点破这一点，评委立刻知道你们真的懂这道题。

**几何：** L/R = 25/2 = 12.5 → 按**无限长圆柱、一维径向**处理是合理的；端面效应留作敏感性分析（有余力可做二维轴对称对照，作为创新点）。

### 4.1 统一控制方程

径向一维、圆柱坐标，`r ∈ [0, R]`：

```
传热：  ρ(C)·c_p(C)·∂T/∂t = (1/r)·∂/∂r( r·k(C)·∂T/∂r )  [ − ρ_d·h_fg·∂C/∂t ]
传质：  ∂C/∂t = (1/r)·∂/∂r( r·D(C,T)·∂C/∂r )
```

方括号项为蒸发潜热汇。问题 1 可略去，问题 2/3/4 建议纳入作为模型升级点，并做"含/不含潜热"的对照。

**边界条件：**
- `r = 0`（对称）：`∂T/∂r = 0`，`∂C/∂r = 0`。圆柱坐标原点奇点用**有限体积法**自然处理（不要用有限差分硬套洛必达）。
- `r = R`（对流）：
  - `−k·∂T/∂r|_R = h·( T_R − T_air(t) )`，h = 25 W/(m²·K)
  - `−ρ_d·D·∂C/∂r|_R = ρ_d·h_m·( C_R − C_air(t) )`，h_m = 8×10⁻⁷ m/s

> ⚠️ **本题最大的量纲陷阱**：h_m 的单位是 m/s（配 kg/m³ 的浓度），而 C 是 kg/kg（干基含水率）。必须在论文里**显式写出换算**：用干基密度 ρ_d 把 kg/kg 转成 kg/m³，两边同乘 ρ_d 后得到上式。烘房侧的 C_air 若按空气湿度理解还需 ρ_air，本题按"同一基准"处理并写成明确假设 + 做敏感性。**这一步写清楚就能甩开一批队伍。**

**初始条件：** `T(r,0) = 28 °C`，`C(r,0) = 2.55 kg/kg`。

**烘房条件：** 附件 1 给出 0–14400 s（4 h）、步长 60 s 的 T_air（28 → 50.2 °C）和 C_air（0.0196 → 0.0499 kg/kg）。**4 h 之后附件没有数据** → 必须写成假设："恒温干燥阶段 T_air = 50 °C、C_air = 0.05 恒定"，并对此做敏感性。

### 4.2 数值方案（一次搭好，四问复用）

**空间：控制体积法（有限体积），Δr = 0.1 cm → 21 个节点（r = 0, 0.1, …, 2.0 cm）。** 界面上的 k、D 用**调和平均**（因为 D 跨 4 个数量级，算术平均会严重高估通量——这一点也值得在论文里说明）。

**时间：**
- 问题 1（常物性）：显式欧拉即可。稳定性核查：`αΔt/Δr² = 1.69×10⁻⁷ × 1 / 10⁻⁶ = 0.169 < 0.5` ✓；`DΔt/Δr² ≈ 5×10⁻³ ≪ 0.5` ✓。**Δt = 1 s 天然稳定**，正好是题目要求的输出步长。
- 问题 2/3/4（变物性、非线性、长时程）：改**全隐式 / Crank–Nicolson + Picard 迭代**，配自适应时间步（干燥后期速率极慢，可用大步长）。问题 3 要积分到几十小时，显式格式会算到天亮。

**验证清单（务必写进论文）：**
1. 常物性 + 恒定边界 → 与 Bessel 级数解析解对拍
2. 全局质量守恒：`d/dt ∫C dV` = 表面通量积分，误差 < 1e-6
3. 网格加密（Δr = 0.05 cm）与时间步减半的收敛性验证
4. 与 Lewis 数 / Biot 数预测的特征时间对照

### 4.3 逐问要点

**问题 1（0–1800 s，常物性）**
- 参数：ρ=820, c_p=2600, k=0.36, h=25, h_m=8e-7, `D = 7×10⁻⁹ e^(-0.89/C)`（注意 D 仍随 C 变，不是常数）。
- 预期结果：30 min 内温度从 28 °C 升到接近但低于烘房温度（Bi_h≈1.4 → 中心明显滞后于表面，能看出温度梯度）；水分几乎没变（τ_C ≫ 1800 s），只有表面薄层有下降。**如果你们算出来 30 min 内水分大幅下降，说明边界条件量纲错了。**
- 输出 result1.xlsx：两个工作表，A 列时间（0–1800 s，步长 1 s），首行距中心距离（0–2.0 cm，步长 0.1 cm）→ 约 1801×21。

**问题 2（0–3 h，变物性）**
- 附录 3 公式：`ρ=650+128C`，`c_p=1450+2736·C/(C+1)`，`k=0.21+0.38·C/(C+1)`，`D=2.4×10⁻³·e^(-0.45/C)·e^(-3850/T)`（T 用 **K**）。
- 现在 ρ、c_p、k、D 全是 C 的函数，D 还依赖 T → **两个方程双向强耦合**，必须迭代求解。
- 建议在此问引入蒸发潜热汇，并对比"含潜热 / 不含潜热"的温度曲线——这是模型精细度的直接体现。

**问题 3（烘干终止时间）**
- 判据：`max_r C(r,t) < 0.15`。因内扩散控制，最慢点必在中心 → 实际是 `C(0,t) < 0.15`。
- 预期量级：**约 48–72 h**（与题面"一般持续 2–3 天"和附件 2 的 72 h 半径数据一致）。若你们算出 5 h 或 500 h，回去查边界条件。
- 干燥后期 D 塌陷到 ~10⁻¹⁰ 量级，收敛极慢，**必须用隐式 + 自适应步长**。
- 论文里画"干燥速率曲线"，指出恒速期 / 降速期的转折，并与表面硬壳机理关联。

**问题 4（收缩 / 移动边界）—— 这是全题最大的区分点**
- 附件 2 给出 R(t)：0 → 259200 s（72 h），步长 1800 s，R 从 2.000 cm 降到 1.198 cm 后稳定。
- 用**朗道变换（Landau transform）**把移动域映射到固定域：令 `ξ = r/R(t) ∈ [0,1]`，则

```
∂C/∂t|_ξ − ( ξ·Ṙ/R )·∂C/∂ξ  =  1/(R²ξ) · ∂/∂ξ( ξ·D·∂C/∂ξ )
```

  左边多出的对流项就是收缩带来的坐标拖曳。**把这一步推导干净地写出来，是 A 题最能拉开差距的一页。**
- 附录 4 用的是另一套物性：`ρ=760+90C`，`c_p=1850+2150·C/(C+1)`，`k=0.12+0.20·C/(C+1)`，`D=4.2×10⁻⁴·e^(-0.30/C)·e^(-3850/T)`。别混用附录 3。
- 需澄清的物理点：干基含水率 C 的定义下，固体骨架质量不变，收缩**不直接改变 C 的定义**，但改变了几何、扩散路径长度和 D 的空间分布。论文里要说清楚。

## 五、B 题思路（备查）

### 问题 1：交会定位与定位区域
- 每个检测点 S_i 的示向度 θ_i 张成一个 **2° 楔形**（凸集）。干扰源必在所有楔形的交集 `P = ∩ W_i` 内。
- 算法：把每个楔形写成两个半平面，用 **Sutherland–Hodgman 凸多边形裁剪**逐次求交 → 得到凸多边形 P 的顶点。
- 定位区域直径 = 顶点集的直径（旋转卡壳 O(n log n)，或直接 O(n²)）。
- **"以直径为直径的圆能否覆盖" → 答案是"不一定"。** 反例：边长 d 的正三角形，直径 = d，以任一边为直径的圆半径 d/2，圆心在该边中点，到对顶点距离 √3·d/2 > d/2，不覆盖。
  正确结论用 **Jung 定理**：平面上直径 d 的集合，最小外接圆半径 ≤ d/√3 ≈ 0.577d。给出反例 + Jung 界，这一小问就满分了。
- 还需处理鲁棒性：≥3 条示向线可能因误差无公共交集（矛盾观测）→ 用"最小化最大违背"的线性规划求可行近似。

### 问题 2：第二检测点选择
- 两点交会的误差区域近似为平行四边形，面积 `≈ (2εd₁)(2εd₂)/sin γ`，其中 d_i 为检测点到源的距离，γ 为两条示向线夹角，ε = 1° = 0.01745 rad。
- 最小化面积 → **γ → 90°（垂直基线）且 d₁, d₂ 尽量小**。
- 约束边界：有效接收半径 1000–1500 m（未知，取保守值）；距离 ≤ 5 m 无示向度；定向源 ±90° 覆盖；移动耗时 = 距离 / 5 m/s。
- 候选区域 = 由 `γ ∈ [60°, 120°]` 与 d 上下界围成的两块关于示向线对称的区域；再叠加"移动时间"权重，给出**精度–时间帕累托前沿**。

### 问题 3：搜索–定位–清除策略
**时间会计（策略设计的基础）：** 移动 = 距离/5 s，换道 = 1 s，检测 = 5 s，清除成功 = 5 s（3 s 定位 + 2 s 清除），未发现 = 3 s。
> 关键洞察：**检测 5 s 只等于移动 25 m，换道仅 1 s。所以"少走路、多测量、原地扫多个频道"极其划算。** 单点扫全 20 频道 = 20×5 + 19×1 = 119 s，只相当于移动 595 m。

**分层策略：**
1. **哨点覆盖设计**：区域半径 1800 m，有效接收半径仅 1000–1500 m → 单点无法覆盖全区。需先解一个**圆盘覆盖问题**：用若干半径 1000 m 的圆覆盖半径 1800 m 的圆盘，且保证任一点被 ≥2 个哨点覆盖（交会定位需要两个点）。这个几何论证本身就是很好的建模内容。
2. **频道普查**：在哨点扫全频，确定哪些频道存在源、并获得初步示向度。
3. **粗定位**：对每个活跃频道，用问题 2 的准则挑第二/第三点交会，把定位区域缩到 < 20 m（清除容差）。
4. **精定位与清除**：走到定位区域重心发 `/clear`。失败则在区域内按 20 m 网格补点，或补测一次示向度。
5. **在线路径规划**：待清除目标构成动态 TSP → 贪心 + 2-opt，每次获得新信息后重规划（rollout / receding horizon）。

**统一框架（推荐）：** 把区域离散成栅格，为每个频道维护一张**源位置概率图**；每次检测的三种返回（`direction` / `near` / `no_signal`）都做贝叶斯更新；动作选择用**信息增益 / 时间代价**比值最大化。这套框架能同时覆盖问题 3 和问题 4，论文结构会非常干净。

### 问题 4：定向干扰源
- 定向源仅在主向 ±90° 内辐射 → `no_signal` 不再等价于"无源或超距"，出现**三义性**。
- 但 `no_signal` 是**负信息**：它排除了"以该点为圆心、半径 1500 m 内且朝向该点"的位形集合 → 在上述概率图框架里天然可以吸收。
- 朝向估计：由"能收到该频道信号的检测点集合"反推源的主向扇区。
- 策略调整：对久扫不到的频道，主动绕到区域另一侧补测（打破朝向盲区）。

## 六、C 题思路（备查）

### 数据结构
- 附件 1：某天 10 min 粒度（144 点）的电价、小区负载(kW)、光伏预测功率(kW)
- 附件 2：2025 全年每天 10 min 粒度的**实际**负载与光伏（用于问题 2/3 的执行回放）
- 附件 3：全年每天 0/6/12/18 四次发布的未来 24 h **整点**光伏预报（1461 行 × 26 列）
- 附件 4：全年 10 min 粒度的**波动电价**（366 行 × 145 列）
- 储能：容量 12000 kWh，最大充放功率 5000 kW，SOC ∈ [1200, 10800]，初值 6000（2025-01-01 0:00），充放电效率 90%

> 单位换算：10 min 时段内，功率 P(kW) × (1/6) h = 电量(kWh)；充放功率上限 5000 kW → 每时段 ≤ 833.33 kWh。

### 问题 1：确定性线性规划
决策变量（t = 1…144）：购电 `g_t ≥ 0`，充电 `ch_t ≥ 0`，放电 `dis_t ≥ 0`，储能 `E_t`，弃光 `cur_t ≥ 0`

```
min  Σ price_t · g_t
s.t. g_t + pv_t/6 − cur_t + dis_t − ch_t  ≥  load_t/6        (供电不低于负载)
     E_t = E_{t−1} + η·ch_t − dis_t/η                        (效率 90%，须写明单程/往返假设)
     1200 ≤ E_t ≤ 10800
     ch_t, dis_t ≤ 833.33
     E_0 = E_144                                             (0:00 与 24:00 储能量相同)
```

**这是纯线性规划，用 `scipy.optimize.linprog` / `PuLP` / `Gurobi` 秒级求全局最优。绝对不要用遗传算法或粒子群——那是这道题最典型的减分项。**

加分：写出**对偶变量 λ_t 的经济解释**（影子电价），说明储能套利的临界条件是 `λ_放 · η ≥ λ_充 / η`，即价差需覆盖 `1/η² ≈ 1.23` 倍的效率损失。这个阈值能直接解释最优充放电时段。

### 问题 2：两阶段随机规划（**报童模型**）
- 每天 0:00 只能基于预测制定**计划购电量**，实际负载/光伏来自附件 2。
- 罚则不对称：买少了 → 紧急购电 **5 倍**电价；买多了 → 多出部分仍按 **50% 违约电价**计费（题面："计划购电量高于调整购电量的部分，违约电价为交易时刻电价的 50%"），且其他时段仍按计划量付费。
- **这是标准报童问题。** 设欠量单位成本 `c_u`（紧急 5 倍，超出计划的额外成本 = 4 倍电价），超量单位成本 `c_o`（约 0.5 倍电价）。最优计划量应取净需求分布的分位数：

```
q* = c_u / (c_u + c_o)      （按 4 : 0.5 计 → q* ≈ 0.89）
```

  **把这个解析分位数写出来，是 C 题最漂亮的可解释性结果**，比任何数值实验都有说服力。具体系数请按你们对题面罚则的最终理解重新推一遍。
- 实操：用历史（前 N 天同时段）预测误差经验分布定分位数 → 计划购电量；储能额外预留 SOC 缓冲应对误差。
- 全年 334 天 × 144 时段 → 每天一个小 LP，注意向量化和求解器 warm start。

### 问题 3：模型预测控制（MPC / 滚动时域）
- 0:00 用当日预报定计划；6:00/12:00/18:00 各重新优化一次 → 调整购电量（超出计划部分按 **1.5 倍**电价）。
- 框架：**receding horizon**，每 6 h 以 24 h 为预测窗口重解，只执行未来 6 h，储能 SOC 作为状态传递。
- 预报是**整点**粒度而决策是 10 min → 需降尺度插值，并说明插值方法对结果的影响。
- 题目问"是否需要引入其他时刻的预报"→ 做 **A/B 对照实验**：仅用 0:00 预报 vs 用全部 4 次预报，比较全年总成本；再用附件 3 统计**预报误差随提前期（1–24 h）的增长曲线**作为机理支撑。这个对照实验是问题 3 的核心答案，别只给个数字。

### 问题 4：波动电价下的随机优化
- 电价改用附件 4（10 min 粒度全年）→ 制定计划时电价本身也是随机变量。
- 需要电价模型：日内周期成分 + 随机扰动（可用历史同时刻经验分布 / AR / 分位数回归）。
- 目标改为 `min E[cost]`；进一步可引入 **CVaR** 做风险厌恶版本，与风险中性版本对比。
- 加分：对比**随机规划**（场景法 SAA）与**鲁棒优化**（min-max 于价格不确定集）两条路线的成本与稳健性。
- 注意价格与负载/光伏可能相关（高负载时高价）→ 检验相关性，若显著则需联合场景抽样而非独立抽样。

### C 题的主要坑
1. 全年 334 天 × 4 问 × 多次重优化 = 上千次 LP，**必须做好向量化和求解器复用**，否则算不完
2. 效率 90% 是单程还是往返，题面未明确 → **写成假设并做敏感性**
3. 问题 2/3/4 若做成"确定性 LP + 事后修补"，就丢掉了全部区分度。**随机性建模才是这道题的分水岭。**
4. 结果文件（result1 ~ result4-3）格式复杂，含多个工作表和"紧急购电时间段"这类非规则表格，**留足格式核对时间**
