## 2. 论文参考文献表建议

- 排序：按正文首次出现顺序编号；`L-xx` 只在本表内部使用，论文里换成阿拉伯数字。
- 字段：作者（姓 + 首字母）· 年份 · 题名 · 期刊/出版社 · 卷(期): 页 · DOI/标识符。
- 只引用**实际使用**的条目（正文出现"文献 [L-xx]"的才进表），避免堆砌。
- 证据等级与相关性评分**不进论文**，只作内部管理字段。

## 3. 检索审计摘要（据实声明，便于论文写"数据来源说明"）

- 检索范围：Crossref / OpenAlex / PubMed / Europe PMC / arXiv / doi.org；
  **Scopus、Web of Science、CNKI、万方未检索**（无可用接口），故不宣称覆盖中文文献。
- 核心 15 篇的 DOI 均通过 Crossref 与 OpenAlex **单条双库核验**；1.1～1.2 组中 8 条有 DOI 核验。
- **Unpaywall 未查询**（其 API 要求真实邮箱，未经授权不外发）；合法开放全文核查状态在两份审计文档中逐条记录。
- 未核验项：L-13、L-14、L-15、L-39 的 DOI；L-16 的实测数据点未数字化（其正文给出参数范围与验证指标，见 06 号 §6）。
- 详细检索式、返回量与去重规则见 `文献/paper_lookup_round1_2026A.md` 与
  `文献/paper_lookup_cylindrical_biological_drying_pde_2026-09-12.md`。
