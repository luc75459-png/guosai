## 3. 逐章素材（下一轮逐章填充）

每章按同一张卡片填写，格式固定：

```text
### 第 N 章 XXX（建议篇幅）
- 本节要证明/说明什么（一句话论点）
- 直接引用的公式：01 式 (x)(y) / 02 式 (z)——不要抄公式，只写式号
- 要放的图/表：图 x / 表 y（编号见本稿 §2）
- 可直接使用的数字：03 §2 的哪几行（或 05 §x）
- 建议措辞（2~5 句，可直接改用）
- 常见追问与应答（防守点，取自本稿 §4.4）
```

**填充顺序**：第 5 章 → 第 6 章 → 第 7.x 章 → 第 8 章 → 第 9 章 → 第 2、3 章 → 摘要。

## 4. 协作与写作纪律

### 4.1 五条纪律

1. **结论前置**：每节第一句就是判断，公式与数字在后。
2. **用表代替形容词**：凡"更准/更稳/更合理"，都换成并列数字（表7 就是范本）。
3. **数字只从 03 §2 取**，不手抄、不口算；表格用 `paper_tables` 生成。
4. **"我们验证了"替代"我们假设"**：全文搜一遍"假设"二字，能换的都换。
5. **版本只出现一套**：正文只写 README §1 的采用版本；备选口径一律进"验证与讨论"或附录，
   并注明"本文最终采用 X，Y 仅作对照"。
