## 2. 采用的算法版本与代码结构

### 2.1 采用的算法版本（主模型配置）

求解器：`AProblemMaterial/`，包名与版本 `cumcm-a-drying-material` **v0.2.0**。

| 组件 | 采用的版本 | 各问差异与备注 |
|---|---|---|
| 空间离散 | **节点中心型有限体积**（控制体法）；圆心与表面为半控制体；界面通量成对抵消 | 四问共用 |
| 界面扩散系数 | 按题号默认：问题1 `midpoint`；**问题2/3/4 `kirchhoff`**（`D_face=ΔΦ/ΔC`） | 问题4 自 2026-09-12 起全队统一到 `kirchhoff`（口径与问题2/3 一致、与队友一致） |
| 界面导热系数 | **中点状态点值** | 通量势只对 `C` 定义，传热侧统一退回中点值（01 号 §6.5） |
| 时间推进 | **二阶显式 Heun（SSPRK2）** + 按节点局部总流出系数的动态稳定步长，`Δt=0.8/λ_max` | 四问共用；BDF 仅用于独立对拍，不作主推进 |
| 终止事件 | `max_r C=0.15` 的**首次穿越**，跨步线性插值定位连续时刻 | 问题3、问题4 |
| 端面 | 主模型**不计端面**（`include_end_faces=False`，只算侧面），报告**中截面口径** | 问题4 的正式结果由一维仅侧面模型给出；端面影响由**二维轴对称模型**（真实 Robin 边界）复验 |
| 问题4 坐标 | **材料坐标** `ξ=r/R(t)`；**不加拖曳项**；每步按当前 `R(t)` 重建真实几何（"写法乙"） | 02 号 §5.2–§5.3 |
| 长度与边界延拓 | `L=0.25 m` 恒定；4 h 后取恒温段 50 ℃ / 0.05 kg/kg（`plateau_mode=fixed`） | 敏感性对照见 05 号 §6.1 |
| 生产网格 | 四问径向 **N=40** | 问题4 端面复验用二维 40×20/40×40/40×80；问题1 的末位不确定度见 03 号 §4.4 |
| 输出 | `resultN.xlsx` 由求解器直接生成 + 自动回读校验；论文表由 `paper_tables` 抽取 | 格式见 §4 |
| 验证引擎（非主推进） | SciPy BDF 对拍、网格/时间收敛扫描、二维退化与守恒闭合测试 | 见 §5 |
| 已否决的备选 | `2h/L` 端面等效源（高估端面作用约 45%）；`harmonic`/`series` 界面（粗网格未收敛）；固定权重混合（按结果反标定的自由参数）；材料坐标再加拖曳项（重复计一次对流）；问题4 的 `midpoint` + 轴向平均口径（2026-09-12 弃用，留档）；问题1 改用 N=160（已备查，本轮不采用） | 逐条依据见 03 号总表与 05 号 §8 |

**论文可直接引用的表述**：

> 本文采用节点中心型有限体积法离散圆柱径向热湿耦合方程。界面扩散系数按题号取用：
> 问题1 取界面中点状态点值，问题2、3、4 取基尔霍夫通量势的差商 `D_face=ΔΦ/ΔC`；
> 界面导热系数统一取中点状态点值。时间推进为二阶显式 Heun
> 方法，配合按节点局部总流出系数确定的动态稳定步长（安全系数 0.8），达标时刻由
> 跨步线性插值定位。主模型不计端面、仅计入圆柱侧面，报告中截面的径向分布；问题4 的
> 端面影响由二维轴对称材料坐标模型（端面为真实 Robin 边界）复验，与一维"仅侧面"解
> 的交叉验证一致到 10⁻⁷ 量级。全部结果文件由求解器直接生成并自动回读校验。

## 3. 命令清单

在 `CUMCM2026Problems/AProblemMaterial/` 下执行：

```powershell
# 0. 单元测试（29 项）
python -m pytest -q

# 1. 四问正式计算
python -m aproblem --question 1 --intervals 40  --output-dir "outputs\问题1\主模型_midpoint_N40"
python -m aproblem --question 2 --intervals 40  --output-dir "outputs\问题2\主模型_kirchhoff_N40"
python -m aproblem --question 3 --intervals 40  --output-dir "outputs\问题3\主模型_kirchhoff_N40" --bdf-check
python -m aproblem.report                       # 问题4：二维正式结果 + 验证报告

# 1b. 问题1 高精度网格（缺口 T2）
python -m aproblem --question 1 --intervals 160 --interface-strategy midpoint `
    --output-dir "outputs\问题1\主模型_midpoint_N160"

# 1c. 问题4 备选口径（缺口 T1，本轮未采用）
python -m aproblem --question 4 --intervals 80 --interface-strategy kirchhoff `
    --output-dir "outputs\问题4\生产_kirchhoff_N80"

# 2. 批量研究（子命令：interface-scan / grid-convergence / time-convergence / sensitivity / axisymmetric-scan）
python -m aproblem.study interface-scan    --intervals 20 40 80 --integrator bdf
python -m aproblem.study grid-convergence  --intervals 20 40 80 160 --integrator bdf
python -m aproblem.study time-convergence  --intervals 40 --dt-list 0.5 0.25 0.125
python -m aproblem.study sensitivity       --intervals 40 --integrator bdf
python -m aproblem.study axisymmetric-scan --radial-intervals 40 --axial-intervals 20 40 80 `
    --interface-strategy midpoint

# 3. 论文表格自动抽取（表1～表6）
python -m aproblem.paper_tables --question 1
python -m aproblem.paper_tables --question 4 --path "outputs\问题4\result4.xlsx" --out "outputs\论文表6.md"

# 4. 验证实验（L0 解析基准 / L1 外部实测对照）
python -m aproblem.analytic      # L0：输出 outputs/study/analytic/
python -m aproblem.external      # L1：输出 outputs/study/external_validation/
python scripts/digitize_teleken.py   # L1 数据：重跑数字化与 QA 叠加图
```

命令行开关（`aproblem`）：`--intervals`、`--interface-strategy {midpoint,harmonic,series,kirchhoff}`、
`--include-end-faces`、`--bdf-check`、`--no-result`、`--attachments`、`--output-dir`。
（`--ignore-end-faces` 为兼容旧脚本而保留，主模型默认不計端面。）

## 6. 验证实验（L0 verification + L1 validation）——已执行

预注册判据见 §9（先于计算冻结）；本节只记录**怎么跑、跑出什么**。

### 6.1 L0 解析基准（verification）

命令：`python -m aproblem.analytic` → `outputs/study/analytic/`。

| 算例 | 内容 | 实测结果 | 判据 |
|---|---|---|---|
| L0-A | 无限长圆柱、常数物性、侧面 Robin 的解析级数解 vs 生产 `DryingModel`；`Bi=0.5/5/50`，`N=10…160` | 观测阶 `1.989–2.178`（要求 1.8–2.2）；`N=40` 最大误差 `1.8×10⁻⁴–4.0×10⁻⁴`；`N=160` `1.1×10⁻⁵–2.5×10⁻⁵` | **全部通过** |
| L0-B | 固定 `N=160`，`Δt=c·Δt_stable`，`c=0.4/0.2/0.1/0.05`，自收敛（逐档差商）测 Heun 时间阶 | 观测阶 `2.000 / 2.002`；最细两档相对差 `7.2×10⁻¹²` | **全部通过** |
| L0-C | 变系数稳态通量：`D(C)=Ae^{−b/C}`，`Φ` 沿 `ln r` 线性，四套界面策略对拍 | 基尔霍夫恒等式残差 `1.5×10⁻¹⁶`；`kirchhoff` 通量误差 `1.6×10⁻³/4.4×10⁻⁴/1.1×10⁻⁴`（N=20/40/80，二阶下降）；`harmonic`/`series` 在 `N=40` 达 `4.0×10⁻¹` | **全部通过** |

判据通过 **20/20**。可写入论文的两条结论：

> 本文的有限体积离散在圆柱 Robin 问题上对解析解呈二阶收敛（观测阶 1.99–2.18），
> Heun 时间推进的观测阶为 2.000–2.002；在变系数稳态扩散中，基尔霍夫界面取法
> `D_face=ΔΦ/ΔC` 使两点通量恒等式精确成立（残差 1.5×10⁻¹⁶），其整域通量误差按
> 二阶下降，而调和平均与圆柱串联阻力式在 `N=40` 仍偏离 40%，两者同源。

### 6.2 L1 外部实测对照（validation）

数据源：Teleken et al. (2025)，*Foods* 14(3):428，PMC11817341（CC BY 4.0）。
实测点由 `scripts/digitize_teleken.py` 从 Figure 4 数字化（两遍独立算法，
18/18 通过质量门；数字化不确定度 `σ≈0.083 kg/kg`），数据落在
`data/external/teleken2025/`，方法与许可证见该目录 `README.md`。

命令：`python -m aproblem.external` → `outputs/study/external_validation/`。

| 指标 | 60 ℃ | 70 ℃ | 判据 | 结论 |
|---|---|---|---|---|
| 水分 `RMSE_X`（零拟合参数） | **0.1036** | **0.0895** | ≤0.35 / ≤0.30 | 通过 |
| 水分 `R²` | **0.9879** | **0.9908** | ≥0.90 | 通过 |
| 降速段偏差 | −0.0542 | −0.0032 | \|·\|≤0.10 | 通过 |
| 到达 `X=1.0` 时间相对误差 | −14.8% | +5.0% | \|·\|≤20% | 通过 |
| 反演 `D` / 论文 `D` | 0.935 | 0.972 | 0.5–2.0 | 通过 |
| 中心温度平台（诊断项） | 60.0 ℃ vs 论文 46 ℃ | 70.0 ℃ vs 论文 53 ℃ | 偏差 ≤5 ℃ | **未通过（已归因）** |

判据通过 **10/12**；两条未通过项均为温度平台，原因是本模型**忽略蒸发潜热**
（这是 01 号 §4.3 已声明的简化），模型中心温度趋近热风温度而实测被蒸发冷却压到
湿球附近。该项按预注册要求原样报告、不调参，并写入"误差与不确定度"章作为
未建模因素的定量证据。

**敏感性（RMSE_X）**：`h_m×0.1/×10` 几乎不改变结果（0.1033–0.1037 / 0.0892–0.0896），
证实该工况传质 Biot 数极大（`Bi_m≈6.8×10⁴`）、过程由内扩散控制；环境值
`X_eq=0.05` 略改善；几何改成体积等效半径 `R=4.92 mm` 使 RMSE 升到 0.25/0.20，
说明**等效几何映射是本次外部对照最大的模型形式不确定度**。

**端面解析界**（替代预注册的二维诊断，理由见 §9.4 偏差记录）：180 min 时
Newman 平板平均因子为 0.942（60 ℃）/0.934（70 ℃），即只算侧面最多高估
5.8%/6.6% 的平均含水率。

## 8. 已知实现陷阱（写代码/改代码时对照）

| # | 陷阱 | 正确做法 | 依据 |
|---|---|---|---|
| 1 | 中心与表面控制体按整格计体积 | 两者只计**半格**（`V_0=Δr²/8`、`V_N=RΔr/2−Δr²/8`） | 01 号式 (18) 与几何恒等式 |
| 2 | 材料坐标下把内部与表面用同一标度缩放 | 内部 ∝`1/R²`、侧面 Robin ∝`1/R`；混用会把表面放大 `(R₀/R)²` | 02 号 §5、命题 B4 |
| 3 | 在材料坐标方程里再加一次拖曳项 | 从材料导数出发时**不加**（两项精确抵消） | 02 号命题 B3 |
| 4 | `ΔΦ/ΔC` 在小 `ΔC` 时灾难性抵消 | `|ΔC|<10⁻⁶max(C,·)` 时退回中点状态点值 | 01 号 §6.4 |
| 5 | `h_m` 与干基含水率直接相乘而不说明口径 | 显式写出 `ρ_d` 换算链与有效系数定义 | 01 号 §3.4 |
| 6 | 界面导热系数用调和平均 | 传热侧用中点值（`k` 连续、只变 2.3 倍） | 01 号 §6.5 |
| 7 | 事件时刻取离散步终点 | 用跨步线性插值定位连续时刻 | 01 号 §7.3 |
| 8 | 问题4 输出按**轴向平均**剖面导出 | 主结果取**中截面**口径（缺口 T9） | 02 号 §6.4 |

### 9.1 L0-A 瞬态圆柱 Robin 解析基准（verification）

设定（无量纲化后与本题物性无关，只检验离散格式）：
`R=0.01 m`、`D=1e-8 m²/s`、`α=D`、初值 `C₀=1.0`、`T₀=100`、环境 `C∞=0.0`、`T∞=20`；
`Bi=hR/D=0.5/5/50`；`Fo=Dt/R²∈{0.01,0.05,0.1,0.2,0.5}`；`r/R∈{0,0.5,1}`；
网格 `N=10/20/40/80/160`。

**执行前确定的实现选择**：L0-A 用同一生产 RHS（`DryingModel`）配 SciPy BDF
（`rtol=1e-11`、`atol=1e-13`），以把时间误差压到远低于空间误差，从而单独测出空
间观测阶；Heun 的时间阶由 L0-B 单独测量。

**判据**：观测阶 `p∈[1.8,2.2]`（N=80→160 及逐次加密的平均）；`N=40` 最大相对误差
`<0.5%`；`N=160 <0.05%`。相对误差以初始到环境的跨度 `(C₀−C∞)`（温度用 `T₀−T∞`）为基准。

### 9.2 L0-B Heun 时间推进阶数

固定 `N=160`、`Bi=5`、`Fo=0.1`；固定步长取 `Δt=c·Δt_stable`，
`c∈{0.4,0.2,0.1,0.05}`（`Δt_stable` 由 `stable_time_step(safety_factor=1)` 给
出）。

**执行前确定的误差定义**：用**自收敛（逐档差商）**而不是外部参照解。定义
`d_k=max|u_k−u_{k+1}|/span`，四档步长用同一空间网格，空间误差在差商中成对抵消，
观测阶取 `log₂(d_k/d_{k+1})`。若改用解析解作参照，四档步长测到的都是空间误差（约 9×10⁻⁶，
与步长无关），无法分离时间误差。

**判据**：观测阶 `p_t∈[1.8,2.2]`；最细两档相对差 `<1e-4`。

### 9.3 L0-C 变系数稳态通量恒等式（基尔霍夫取法的直接检验）

环形域 `[R₁,R₂]=[5 mm,20 mm]`，`D(C)=2.4×10⁻³e^{−0.45/C}e^{−3850/T}`，`T=323.15 K`，
端值 `C(R₁)=2.5`、`C(R₂)=0.15`。精确解由 `Φ(C(r))` 沿 `ln r` 线性给出，
总通量 `J=2π[Φ(C₁)−Φ(C₂)]/ln(R₂/R₁)`。

**判据（执行前修正记录）**：原计划写"`kirchhoff` 逐面通量对精确 `J` 的相对误差
`<1e-10`"，该表述在数学上不成立——逐面通量与精确 `J` 的差别含 `ln(r_{i+1}/r_i)`
的 `O(Δr²)` 几何离散误差，不可能到机器精度。修正发生在**任何计算之前**，
原因是公式形式化错误，不是结果驱动。修正后拆成两条：

- **C1（恒等式，主判据）**：`max|D_face·ΔC − ΔΦ|/|ΔΦ| < 1e-12`，`N=20/40/80`；
  这是 `D_face=ΔΦ/ΔC` 唯一性的直接验证。
- **C2（整域通量）**：`kirchhoff` 最大相对通量误差在 `N=20/40/80` 分别
  `<0.2%/0.05%/0.015%`，观测阶 `∈[1.8,2.2]`；`harmonic` 与 `series` 在 `N=40`
  的误差 `>5%`；`midpoint` 误差介于两者之间。

### 9.4 L1 Teleken (2025) 外部实测对照（validation）

数据源：Teleken et al. (2025), *Foods* 14(3):428, PMC11817341（CC BY 4.0）。
实测点来自 Figure 4（`X_db`–时间，含误差棒）与 Figure 2(b)（中心/中层温度）。

映射规则（预注册，不得事后修改）：等效有限圆柱 `R=5.51 mm`、`L=51.6 mm`；
主算例为一维仅侧面，二维轴对称 `40×40` 作端面诊断；水分 `D` 固定取对方每工况
拟合值（60 ℃：`6.5e-10`；70 ℃：`8.5e-10`），不做温度耦合；`h_m` 取 `0.008/0.007 m/s`；
`X_eq=0`，并做 `h_m×0.1/×10` 与环境值 `0.02/0.05` 的敏感性扫描；
`X₀=4.0 kg/kg`，敏感性 `3.0/3.9`；温度诊断物性按对方 Table 1 在 `x_w=0.78`、
`T=T_air` 处取值；输出时刻严格落在对方的 9 个采样时刻上。

**数字化质量门**：两次独立数字化逐点满足 `|Δ| ≤ max(1% 读数, 0.03 kg/kg)`；
未过门的点重做，仍不过门则整点剔除并在 CSV 标 `included=false`。

**判据**：

- 水分：两工况 `R² ≥ 0.90`；`RMSE_X ≤ 0.35 kg/kg`（60 ℃）/`≤0.30`（70 ℃）；
  降速段 `|bias| ≤ 0.10 kg/kg`；预测到达 `X=1.0` 的时间与实际相差 `≤20%`。
- 温度（诊断项，放宽）：中心准稳态 `46/53 ℃ ± 5 ℃`；`RMSE_T ≤ 4 ℃`。
  超差时归因于"忽略蒸发潜热"这一已声明简化，只报告、不调参。
- 反演（L1-B）：反演 `D` 与对方报告值之比落在 `[0.5,2.0]`。

任何未达标项原样写入报告，并标注原因属于"模型形式差异"还是"数字化误差"。

**执行前偏差记录（均发生在 L1 计算之前，判据与阈值不变）**：

1. **初值改为实测起点**：原计划写 `X₀=4.0`；数字化后 70 ℃ 批的实测起点只有
   `3.44 kg/kg`（60 ℃ 批为 `3.83`）。主算例改用各自实测起点，使模型与实测处于
   同一初始状态；原 `X₀=4.0` 作为预注册敏感性保留并报告。
2. **端面诊断改用 Newman 解析界**：原计划用二维轴对称 `40×40` 作端面诊断。该工
   况的传质 Biot 数约 `6.8×10⁴`，显式/密集隐式积分在 `40×40` 上的代价超出本轮
   时间预算，故改用**有限圆柱乘积解的轴向因子**（Newman）给出端面影响的解析上
   界，并在报告中说明该替换。
3. **不做等温线换算**：论文式 (5) 为气相浓度驱动，其式 (10) 吸附等温线在开放
   全文中的 MathML 结构无法无歧义重建（按可重建形式代入，低含水率端给出
   `a_w≈1`，与脱附数据矛盾）。因此仍按预注册口径直接采用 `h_m`，并以
   `h_m×0.1/×10` 与环境值敏感性覆盖该不确定性。
