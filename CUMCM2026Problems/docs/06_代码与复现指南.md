## 2. 采用的算法版本与代码结构

### 2.1 采用的算法版本（主模型配置）

求解器：`AProblemMaterial/`，包名与版本 `cumcm-a-drying-material` **v0.2.0**。

| 组件 | 采用的版本 | 各问差异与备注 |
|---|---|---|
| 空间离散 | **节点中心型有限体积**（控制体法）；圆心与表面为半控制体；界面通量成对抵消 | 四问共用 |
| 界面扩散系数 | 按题号默认：问题1 `midpoint`；**问题2/3/4 `kirchhoff`**（`D_face=ΔΦ/ΔC`） | 问题4 自 2026-09-12 起全队统一到 `kirchhoff`（口径与问题2/3 一致、与队友一致） |
| 界面导热系数 | **中点状态点值** | 通量势只对 `C` 定义，传热侧统一退回中点值（01 号 §6.5） |
| 时间推进 | **二阶显式 Heun（SSPRK2）** + 按节点局部总流出系数的动态稳定步长，`Δt=0.8/λ_max` | 四问共用；BDF 仅用于独立对拍，不作主推进 |
| 终止事件 | `max_r C=0.15` 的**首次穿越**，跨步线性插值定位连续时刻 | 问题3、问题4 |
| 端面 | 主模型**不计端面**（`include_end_faces=False`，只算侧面），报告**中截面口径** | 问题4 的正式结果由一维仅侧面模型给出；端面影响由**二维轴对称模型**（真实 Robin 边界）复验 |
| 问题4 坐标 | **材料坐标** `ξ=r/R(t)`；**不加拖曳项**；每步按当前 `R(t)` 重建真实几何（"写法乙"） | 02 号 §5.2–§5.3 |
| 长度与边界延拓 | `L=0.25 m` 恒定；4 h 后取恒温段 50 ℃ / 0.05 kg/kg（`plateau_mode=fixed`） | 敏感性对照见 05 号 §6.1 |
| 生产网格 | 四问径向 **N=40** | 问题4 端面复验用二维 40×20/40×40/40×80；问题1 的末位不确定度见 03 号 §4.4 |
| 输出 | `resultN.xlsx` 由求解器直接生成 + 自动回读校验；论文表由 `paper_tables` 抽取 | 格式见 §4 |
| 验证引擎（非主推进） | SciPy BDF 对拍、网格/时间收敛扫描、二维退化与守恒闭合测试 | 见 §5 |
| 已否决的备选 | `2h/L` 端面等效源（高估端面作用约 45%）；`harmonic`/`series` 界面（粗网格未收敛）；固定权重混合（按结果反标定的自由参数）；材料坐标再加拖曳项（重复计一次对流）；问题4 的 `midpoint` + 轴向平均口径（2026-09-12 弃用，留档）；问题1 改用 N=160（已备查，本轮不采用） | 逐条依据见 03 号总表与 05 号 §8 |

**论文可直接引用的表述**：

> 本文采用节点中心型有限体积法离散圆柱径向热湿耦合方程。界面扩散系数按题号取用：
> 问题1 取界面中点状态点值，问题2、3、4 取基尔霍夫通量势的差商 `D_face=ΔΦ/ΔC`；
> 界面导热系数统一取中点状态点值。时间推进为二阶显式 Heun
> 方法，配合按节点局部总流出系数确定的动态稳定步长（安全系数 0.8），达标时刻由
> 跨步线性插值定位。主模型不计端面、仅计入圆柱侧面，报告中截面的径向分布；问题4 的
> 端面影响由二维轴对称材料坐标模型（端面为真实 Robin 边界）复验，与一维"仅侧面"解
> 的交叉验证一致到 10⁻⁷ 量级。全部结果文件由求解器直接生成并自动回读校验。

## 3. 命令清单

在 `CUMCM2026Problems/AProblemMaterial/` 下执行：

```powershell
# 0. 单元测试（29 项）
python -m pytest -q

# 1. 四问正式计算
python -m aproblem --question 1 --intervals 40  --output-dir "outputs\问题1\主模型_midpoint_N40"
python -m aproblem --question 2 --intervals 40  --output-dir "outputs\问题2\主模型_kirchhoff_N40"
python -m aproblem --question 3 --intervals 40  --output-dir "outputs\问题3\主模型_kirchhoff_N40" --bdf-check
python -m aproblem.report                       # 问题4：二维正式结果 + 验证报告

# 1b. 问题1 高精度网格（缺口 T2）
python -m aproblem --question 1 --intervals 160 --interface-strategy midpoint `
    --output-dir "outputs\问题1\主模型_midpoint_N160"

# 1c. 问题4 备选口径（缺口 T1，本轮未采用）
python -m aproblem --question 4 --intervals 80 --interface-strategy kirchhoff `
    --output-dir "outputs\问题4\生产_kirchhoff_N80"

# 2. 批量研究（子命令：interface-scan / grid-convergence / time-convergence / sensitivity / axisymmetric-scan）
python -m aproblem.study interface-scan    --intervals 20 40 80 --integrator bdf
python -m aproblem.study grid-convergence  --intervals 20 40 80 160 --integrator bdf
python -m aproblem.study time-convergence  --intervals 40 --dt-list 0.5 0.25 0.125
python -m aproblem.study sensitivity       --intervals 40 --integrator bdf
python -m aproblem.study axisymmetric-scan --radial-intervals 40 --axial-intervals 20 40 80 `
    --interface-strategy midpoint

# 3. 论文表格自动抽取（表1～表6）
python -m aproblem.paper_tables --question 1
python -m aproblem.paper_tables --question 4 --path "outputs\问题4\result4.xlsx" --out "outputs\论文表6.md"
```

命令行开关（`aproblem`）：`--intervals`、`--interface-strategy {midpoint,harmonic,series,kirchhoff}`、
`--include-end-faces`、`--bdf-check`、`--no-result`、`--attachments`、`--output-dir`。
（`--ignore-end-faces` 为兼容旧脚本而保留，主模型默认不計端面。）

## 6. 外部对照（缺口 T7）的执行方案

**定位**：这是**模型类别验证**（同类材料上"一维径向 Fick + Fourier + Robin"能否复现实测行为），
**不是**对本题答案的验证（本题没有实测数据）。

**首选文献**：Teleken et al. (2025)，*Foods* 14(3):428，PMC11817341（开放全文）。
正文与表格可直接读取的公开数字：

| 类别 | 数值 |
|---|---|
| 拟合参数范围 | `h_T=57.0~62.9 W/(m²·K)`；`h_m=0.007~0.008 m/s`；`D_eff=6.5~8.5×10⁻¹⁰ m²/s` |
| 工况 | 热风 60 ℃ 与 70 ℃，强制循环；虾体（不规则 3D，与等效有限圆柱比较） |
| 实验事实 | 中心温度由 25 ℃ 升到约 46 ℃（60 ℃ 工况）／53 ℃（70 ℃ 工况）；恒速段干燥速率约 0.04／0.05 kg·kg⁻¹·min⁻¹ |
| 验证指标 | `R²≥0.95`；`RMSE_T=0.50 ℃（60 ℃）/1.12 ℃（70 ℃）`；`RMSE_Xdb=0.22/0.16 kg/kg` |

**做法**：把上述参数翻译成我们的配置（常数 `D_eff`、Robin 边界 `h_T/h_m`、初值 25 ℃、
无收缩、几何取等效有限圆柱），用本求解器复算，比较上表 4～6 个公开数字。
**边界形式差异须写明**：对方用气相浓度/水活度 + 潜热，我们用固相有效系数
（01 号式 (11) 给出换算关系），因此只能做量级与关键数字复现，不做逐点比对。
**产出**：一段"外部对照"小节素材 + 复现脚本 + 数据表（写入本档或 03 号总表）。

## 8. 已知实现陷阱（写代码/改代码时对照）

| # | 陷阱 | 正确做法 | 依据 |
|---|---|---|---|
| 1 | 中心与表面控制体按整格计体积 | 两者只计**半格**（`V_0=Δr²/8`、`V_N=RΔr/2−Δr²/8`） | 01 号式 (18) 与几何恒等式 |

| 5 | `h_m` 与干基含水率直接相乘而不说明口径 | 显式写出 `ρ_d` 换算链与有效系数定义 | 01 号 §3.4 |

| 8 | 问题4 输出按**轴向平均**剖面导出 | 主结果取**中截面**口径（缺口 T9） | 02 号 §6.4 |
